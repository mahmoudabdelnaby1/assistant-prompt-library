# PitchCraft Pro

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/140-pitchcraft-pro/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/140-pitchcraft-pro/)

## What it does

PitchCraft Pro architects pitch decks slide by slide, adapted to the deciding audience (investor, client, board, partner): each slide ships with its story job, a message headline (not a label), exact content copy, producible visual direction, and speaker notes — plus the momentum map, Q&A armor with answer frameworks, and the data-harvesting list for honest slots. Traction and financials are never fabricated.

## متى يفيدك؟

يقدم مهندسو PitchCraft Pro عروضًا تقديمية شريحة تلو الأخرى، وتتكيف مع الجمهور المحدد (المستثمر، العميل، مجلس الإدارة، الشريك): تأتي كل شريحة مع وظيفة القصة الخاصة بها، وعنوان الرسالة (وليس التسمية)، ونسخة المحتوى الدقيقة، والتوجيه المرئي القابل للإنتاج، وملاحظات المتحدث - بالإضافة إلى خريطة الزخم، ودرع الأسئلة والأجوبة مع أطر الإجابات، وقائمة جمع البيانات للفتحات الصادقة. لا يتم تصنيع الجر والبيانات المالية أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your project and who decides — investors, a client, your board. You'll get the complete deck document: strategy, every slide built, momentum map, and the numbers you need to gather.

## A useful first message

Create a six-slide pitch outline for presenting an online coffee store to a potential partner. Define each slide’s message and the data I need to collect; do not invent market figures.

## طريقة البدء

قم بوصف مشروعك ومن الذي سيقرر – المستثمرون، العميل، مجلس الإدارة. ستحصل على مستند المجموعة الكامل: الإستراتيجية، وكل شريحة تم إنشاؤها، وخريطة الزخم، والأرقام التي تحتاج إلى جمعها.

**مثال لرسالتك الأولى:**

أعد عرضًا من 6 شرائح لشرح فكرة متجر قهوة إلكتروني لشريك محتمل. حدّد رسالة كل شريحة والبيانات التي أحتاج جمعها، ولا تخترع أرقامًا للسوق.
