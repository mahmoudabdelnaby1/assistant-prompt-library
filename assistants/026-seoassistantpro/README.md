## What it does

SEOAssistantPro delivers an on-page optimization kit for a page or topic: intent diagnosis, a text SERP preview, meta title and description variants within long-stable ranges, heading architecture, a keyword map with placement guidance, content brief, internal linking, and a technical checklist. Volatile specifics are flagged for checking; retired tactics are warned against, not recommended.

## متى يفيدك؟

يقدم SEOAssistantPro مجموعة أدوات تحسين على الصفحة لصفحة أو موضوع: تشخيص النية، ومعاينة النص SERP، والعنوان التعريفي ومتغيرات الوصف ضمن نطاقات طويلة ومستقرة، وبنية العنوان، وخريطة الكلمات الرئيسية مع إرشادات الموضع، وملخص المحتوى، والربط الداخلي، وقائمة مرجعية فنية. يتم وضع علامة على التفاصيل المتقلبة للتحقق منها؛ يتم التحذير من التكتيكات المتقاعدة، ولا ينصح بها.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a page topic or draft plus your target keyword and market. You'll get the complete kit — SERP preview, metas, heading tree, keyword map, content guidance — ready to implement.

## A useful first message

I am creating a specialty coffee store page targeting “specialty coffee for beginners in Egypt.” Suggest a title, meta description, page outline, and relevant FAQs. Do not claim search volume without a source.

## طريقة البدء

أرسل موضوع صفحة أو مسودة بالإضافة إلى الكلمة الرئيسية والسوق المستهدفين. ستحصل على المجموعة الكاملة — معاينة SERP، والتعريفات التعريفية، وشجرة العناوين، وخريطة الكلمات الرئيسية، وإرشادات المحتوى — جاهزة للتنفيذ.

**مثال لرسالتك الأولى:**

أكتب صفحة لمتجر قهوة مختصة تستهدف عبارة «قهوة مختصة للمبتدئين في مصر». اقترح عنوانًا ووصفًا ومخطط الصفحة وأسئلة شائعة مرتبطة بنية الباحث. لا تدّعِ معرفة حجم البحث من دون مصدر.
