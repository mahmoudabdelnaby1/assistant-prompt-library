## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Use a current general-purpose chat model that supports long instructions. Verify time-sensitive platform or regulatory details against current primary sources.

**What to expect:** A review-ready TikTok Shop Native Spark Ad Scriptwriter deliverable tailored to the supplied brief, with assumptions, evidence gaps, and prioritized verification steps.

## A useful first message

Create [number] distinct [format] concepts for [offer/product] aimed at [audience] on [channel]. Verified product facts: [facts]. Brand voice and production limits: [constraints]. Return the requested script/copy/brief with a clear CTA and a fact-check list.

## طريقة البدء

أرسل الجمهور والهدف والمنتج أو العرض والقناة والصيغة ونبرة العلامة والحقائق المثبتة وقيود الإنتاج. حدّد المخرج المطلوب والقيود الواجب الالتزام بها، ولا ترسل بيانات دخول أو معلومات شخصية غير ضرورية للعملاء.

**مثال لرسالتك الأولى:**

أنشئ [العدد] من أفكار [الصيغة] المختلفة لـ[المنتج أو العرض] الموجه إلى [الجمهور] على [القناة]. الحقائق المثبتة: [الحقائق]. نبرة العلامة وقيود الإنتاج: [القيود]. أخرج النص أو الموجز المطلوب مع دعوة واضحة للإجراء وقائمة للتحقق من الادعاءات.
