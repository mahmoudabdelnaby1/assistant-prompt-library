# Topic Plus

**Category:** General Assistants
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/123-topic-plus/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/123-topic-plus/)

## What it does

Topic Plus is a topic-exploration compass: any topic in any language receives a clear beginner-suitable explanation (terms translated, analogy-anchored, honestly bounded), then ten curated subtopic recommendations — each tagged by its role in the knowledge map (foundation, branch, application, frontier, controversy, connection) with a real why-it-matters — plus three exploration paths. Feed any subtopic back and it recurses to the next depth.

## متى يفيدك؟

Topic Plus عبارة عن بوصلة لاستكشاف الموضوع: يتلقى أي موضوع في أي لغة شرحًا واضحًا ومناسبًا للمبتدئين (المصطلحات المترجمة، والقياس المرتكز، والمحدد بصدق)، ثم عشر توصيات موضوعية فرعية منسقة - يتم وضع علامة على كل منها حسب دوره في خريطة المعرفة (الأساس، الفرع، التطبيق، الحدود، الجدل، الاتصال) مع سبب حقيقي لأهميته - بالإضافة إلى ثلاثة مسارات استكشاف. قم بتغذية أي موضوع فرعي مرة أخرى وسيعود إلى العمق التالي.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Name any topic — one word works, in any language. You'll get the explanation, the ten-subtopic map with roles and payoffs, and the builder's / curious / practitioner paths. Any subtopic can be fed back for the next level.

## A useful first message

I am a beginner and want to understand [concept or lesson]. Explain it step by step in plain language, show one worked example, then give me a practice question with a hint before the answer.

## طريقة البدء

قم بتسمية أي موضوع - كلمة واحدة تعمل بأي لغة. ستحصل على الشرح، والخريطة المكونة من عشرة مواضيع فرعية مع الأدوار والمكافآت، ومسارات البناء/الفضوليين/الممارسين. يمكن تغذية أي موضوع فرعي مرة أخرى للمستوى التالي.

**مثال لرسالتك الأولى:**

أنا مبتدئ وأريد فهم [المفهوم أو الدرس]. اشرحه خطوة خطوة بلغة بسيطة، أعطني مثالًا محلولًا، ثم سؤالًا أتدرب عليه مع تلميح قبل الحل.
