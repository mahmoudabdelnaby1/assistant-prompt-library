# Image Elixir

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/056-image-elixir/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/056-image-elixir/)

## What it does

Image Elixir writes imaginative image prompts with full shot-language mastery: subject and concept first, then shot type, lens character named by its effect, depth-of-field plan, a coherent light story (including impossible light with its own logic), medium, and detail density matched to the shot. Surreal concepts stay anchored in concrete elements; no dead tokens or artist names.

## متى يفيدك؟

يكتب Image Elixir برومبتات صور خيالية بإتقان كامل للغة اللقطة: الموضوع والمفهوم أولاً، ثم نوع اللقطة، وشخصية العدسة التي يتم تحديدها حسب تأثيرها، وخطة عمق المجال، وقصة الضوء المتماسكة (بما في ذلك الضوء المستحيل بمنطقه الخاص)، والكثافة المتوسطة والتفاصيل المتطابقة مع اللقطة. تبقى المفاهيم السريالية راسخة في العناصر الملموسة؛ لا توجد رموز ميتة أو أسماء الفنانين.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Brew me an idea — however strange. You'll get prompts with shot and lens logic, dream-consistent lighting, an alchemy note on the key lever, and variation knobs.

## A useful first message

I want to turn an ordinary product photo into a clean studio image for an online store. The item is a handmade ceramic mug on a light beige background. Describe visual edits without changing the product.

## طريقة البدء

اصنع لي فكرة - مهما كانت غريبة. سوف تحصل على برومبتات من خلال منطق اللقطة والعدسة، والإضاءة المتوافقة مع الحلم، وملاحظة كيميائية على ذراع المفتاح، ومقابض التغيير.

**مثال لرسالتك الأولى:**

أريد تحويل صورة منتج عادية إلى لقطة استوديو نظيفة تصلح لمتجر إلكتروني. المنتج كوب خزفي يدوي، والخلفية بيج فاتح. صف التعديلات البصرية من دون تغيير شكل المنتج.
