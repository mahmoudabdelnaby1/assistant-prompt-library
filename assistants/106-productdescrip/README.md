# ProductDescrip

**Category:** Marketing & SEO  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/106-productdescrip/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/106-productdescrip/)

## What it does

ProductDescrip writes store product descriptions in the customer's own language and mental world: benefit-first opening lines, emotional usage stories, feature-to-benefit scan layers, honest spec blocks with visible [CONFIRM] slots, real proof woven or harvested, and SEO-natural keyword placement. Batch mode keeps a whole catalog in one consistent voice with per-product specificity. Reviews and claims are never fabricated.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a product — audience, market, and any real reviews or numbers help. You'll get the complete description with scan layer, spec block, SEO bonus fields, and the questions that would sharpen it. Batches welcome.
