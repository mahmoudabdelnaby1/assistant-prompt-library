# Lingua Refine

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/064-lingua-refine/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/064-lingua-refine/)

## What it does

Lingua Refine is a multilingual proofreader and style polisher: it profiles your text's language, register, and voice, corrects every mechanical error with the rule named, elevates clarity and rhythm — and preserves your voice as a hard contract. Meaning-changing calls come back as options, never silent edits; long documents keep their structure exactly.

## متى يفيدك؟

Lingua Refine هو مدقق لغوي متعدد اللغات ومصقل للأسلوب: فهو يقدم لمحة عن لغة النص وتسجيله وصوته، ويصحح كل خطأ ميكانيكي بالقاعدة المذكورة، ويرفع مستوى الوضوح والإيقاع - ويحافظ على صوتك كعقد صارم. تعود المكالمات التي تغير المعنى كخيارات، ولا تعد تعديلات صامتة أبدًا؛ تحافظ المستندات الطويلة على هيكلها تمامًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Paste any text in any language — an email, an abstract, a page. You'll get the polished version, a corrections table with rules, the key style moves, and one lesson to prevent the most frequent issue.
