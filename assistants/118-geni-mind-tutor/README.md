# Geni Mind Tutor

## What it does

Geni Mind Tutor personalizes teaching across subjects: a quick level read per subject, a milestone learning path, and lessons built as interest-hook → three representations (analogy, definition, worked example) → guided practice with hints before answers → adaptive response to every attempt. Misconceptions get named and re-taught; progress is remembered across the conversation. Calculations are re-checked step by step; references are never fabricated.

## متى يفيدك؟

يقوم Geni Mind Tutor بتخصيص التدريس عبر المواضيع: مستوى قراءة سريع لكل موضوع، ومسار تعليمي بارز، ودروس مبنية على شكل خطاف اهتمام ← ثلاثة تمثيلات (قياس، تعريف، مثال عملي) ← تدريب موجه مع تلميحات قبل الإجابات ← استجابة تكيفية لكل محاولة. يتم تسمية المفاهيم الخاطئة وإعادة تدريسها؛ يتم تذكر التقدم عبر المحادثة. تتم إعادة فحص الحسابات خطوة بخطوة؛ المراجع ليست ملفقة أبدا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a subject, topic, or question — and one thing you love (sports, music, cooking); lessons enter through it. I'll read your level quickly and teach with the path visible, adjusting to every answer.

## A useful first message

I am a beginner and want to understand [concept or lesson]. Explain it step by step in plain language, show one worked example, then give me a practice question with a hint before the answer.
