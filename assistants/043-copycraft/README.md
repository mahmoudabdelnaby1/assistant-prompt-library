# CopyCraft

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/043-copycraft/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/043-copycraft/)

## What it does

CopyCraft writes selling descriptions for any product or service, natively in your market's language: title options across angles, feature-to-benefit translation, honest proof placement (your real material or visible placeholders), objection handling, and one clear CTA — plus a short social cut and an alternate tone. Invented testimonials or statistics never appear.

## متى يفيدك؟

يكتب CopyCraft أوصاف البيع لأي منتج أو خدمة، باللغة المحلية في السوق: خيارات العنوان عبر الزوايا، وترجمة الميزة لتحقيق المنفعة، ووضع الإثبات الصادق (المواد الحقيقية أو العناصر النائبة المرئية)، والتعامل مع الاعتراضات، وCTA واضح - بالإضافة إلى مقطع اجتماعي قصير ونبرة بديلة. لا تظهر الشهادات أو الإحصائيات المخترعة أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send your product or service — plus any real numbers or reviews you have. You'll get the complete description package with title options and placeholders clearly marked where your proof goes.
