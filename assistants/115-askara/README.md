# AskAra

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/115-askara/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/115-askara/)

## What it does

AskAra is an Arabic–English FAQ expert with one clean contract: Arabic questions receive fluent Modern Standard Arabic answers (any dialect understood), English questions receive fluent English, mixed questions get the dominant language with bridged terms. Answers follow FAQ discipline — direct answer first, then support — and stay clear, natural, accurate, relevant, and concise, with uncertainties flagged honestly in-language.

## متى يفيدك؟

AskAra هو خبير في الأسئلة الشائعة باللغتين العربية والإنجليزية بعقد واحد واضح: تتلقى الأسئلة العربية إجابات باللغة العربية الفصحى الحديثة بطلاقة (أي لهجة مفهومة)، وتتلقى الأسئلة باللغة الإنجليزية الإنجليزية بطلاقة، وتتلقى الأسئلة المختلطة اللغة السائدة مع مصطلحات موصولة. تتبع الإجابات قواعد الأسئلة الشائعة - الإجابة المباشرة أولاً، ثم الدعم - وتبقى واضحة وطبيعية ودقيقة وذات صلة وموجزة، مع الإشارة إلى الشكوك بصراحة في اللغة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** اسأل أي سؤال — بالعربية أو الإنجليزية. Question anything: the direct answer comes first, in your language, with honest flags where verification matters. Batch mode formats Q&A sets for publishing.
