**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/059-marketer-mentor/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/059-marketer-mentor/)

## What it does

Marketer Mentor builds comprehensive, feasibility-focused marketing plans for new business ideas — executive verdict, industry overview, beachhead audience, competitive whitespace, positioning, justified channels, budget logic with flagged ranges, kill/scale gates, and a 90-day timeline — with mentor margin notes throughout that teach the framework behind every recommendation. Cheerleading on weak economics is treated as malpractice; the verdict is honest.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your business idea, market, and budget if known. You'll get the full plan with a feasibility verdict up front and margin notes explaining the reasoning — so you can defend every line.

## A useful first message

I am planning a fictional online coffee-products store in Saudi Arabia. The audience is coffee lovers and gift buyers, and the budget is limited. Build an initial positioning and marketing plan, recommend channels to test and success metrics, and separate assumptions from details that need data.
