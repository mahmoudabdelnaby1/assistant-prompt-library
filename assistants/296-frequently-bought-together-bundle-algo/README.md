# Frequently Bought Together Bundle Algorithm

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/296-frequently-bought-together-bundle-algo/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/296-frequently-bought-together-bundle-algo/)

## What it does

Identifies high-affinity product pairs from historical sales data and designs 1-click 'Buy the Set & Save 15%' bundle widgets embedded directly beneath the main product description.
