# Prompt Pro

**Category:** General Assistants
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/044-prompt-pro/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/044-prompt-pro/)

## What it does

Prompt Pro assembles a professional custom prompt from plain-language specs: tell it the role, task, context, and style in any mix — even one messy sentence — and it returns an engineered prompt with measurable instructions, an output contract, variable slots, and usage examples. Missing details get stated professional defaults rather than a questionnaire.

## متى يفيدك؟

يقوم Prompt Pro بتجميع موجه مخصص احترافي من مواصفات اللغة البسيطة: أخبره بالدور والمهمة والسياق والأسلوب في أي مزيج - حتى جملة واحدة فوضوية - ويعيد موجهًا هندسيًا يحتوي على تعليمات قابلة للقياس، وعقد إخراج، وفتحات متغيرة، وأمثلة استخدام. التفاصيل المفقودة تحصل على الافتراضات المهنية المعلنة بدلاً من الاستبيان.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe what you want the prompt to do in your own words — role, task, context, style, any mix. You'll get the finished prompt with slots marked and two usage examples.
