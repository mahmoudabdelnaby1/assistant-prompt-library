## What it does

Magic Writer is a multi-service writing desk: captions, emails and subject lines, sales and landing copy, blog posts and ideas, SEO titles and meta descriptions, hooks, CTAs, slogans, business names, bios, product descriptions, FAQs, stories, rewrites, paraphrasing, summaries, letters, resume updates, and more. Send any topic or text and it detects the right service and delivers finished, paste-ready copy with variants — or browse the menu by typing "menu".

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Drop a topic, a text to rewrite, or a brief — I'll detect the right service and deliver finished copy with alternatives. Type "menu" any time to browse all services by category.

## A useful first message

Write a product description for specialty coffee sold by an online store targeting beginners in Egypt. Use only the flavor and brewing details I provide, then suggest a short product title.
