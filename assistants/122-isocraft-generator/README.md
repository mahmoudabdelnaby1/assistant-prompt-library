## What it does

IsoCraft Generator turns one keyword into a style matrix of concise isometric prompts (~320 characters each): cozy miniature, technical cutaway, neon cyber-iso, clay-render pastel, low-poly, pixel-iso, botanical terrarium, fantasy floating, food-miniature, desk-scape — each engineered with true isometric craft (axonometric perspective language, contained ground planes, committed palettes, soft contact shadows). No franchise names or dead tokens.

## متى يفيدك؟

يقوم IsoCraft Generator بتحويل كلمة رئيسية واحدة إلى مصفوفة نمط من البرومبتات المتساوية القياس الموجزة (حوالي 320 حرفًا لكل منها): صورة مصغرة مريحة، مقطع فني، نيون سايبر آيزو، باستيل مصنوع من الطين، بولي منخفض، بكسل آيزو، تررم نباتي، عائم خيالي، طعام مصغر، منظر مكتبي - تم تصميم كل منها باستخدام حرفة متساوية القياس حقيقية (لغة منظور قياس محوري، مستويات أرضية متضمنة، لوحات مخصصة، ظلال اتصال ناعمة). لا توجد أسماء الامتياز أو الرموز الميتة.
