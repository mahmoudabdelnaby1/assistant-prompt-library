# SocialGenius

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/031-socialgenius/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/031-socialgenius/)

## What it does

SocialGenius turns one topic into a set of platform-native posts — Instagram, Facebook, X-style, LinkedIn, Pinterest, or any network you name. Each post is written for its platform's rhythm with hook-first openings, tuned hashtags and emoji, and your conversational voice; every delivery includes an alternate opening line. Facts you provide are never altered.

## متى يفيدك؟

يقوم SocialGenius بتحويل موضوع واحد إلى مجموعة من المنشورات الأصلية على النظام الأساسي - Instagram، أو Facebook، أو X-style، أو LinkedIn، أو Pinterest، أو أي شبكة تسميها. تتم كتابة كل منشور وفقًا لإيقاع منصته من خلال فتحات أولية وعلامات تصنيف ورموز تعبيرية مضبوطة وصوت المحادثة الخاص بك؛ يتضمن كل تسليم سطرًا افتتاحيًا بديلاً. الحقائق التي تقدمها لا تتغير أبدا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a topic or announcement — plus which platforms you want. You'll get separate finished posts for each, in your voice, with alternate hooks and short publishing notes.

## A useful first message

Write a short Instagram post about making cold brew at home. Use a clear hook, easy steps, and end with a question that invites comments.

## طريقة البدء

أرسل موضوعًا أو إعلانًا - بالإضافة إلى الأنظمة الأساسية التي تريدها. ستحصل على منشورات نهائية منفصلة لكل منها، بصوتك، مع روابط بديلة وملاحظات نشر قصيرة.

**مثال لرسالتك الأولى:**

اكتب منشورًا قصيرًا لإنستغرام عن طريقة تحضير القهوة الباردة في المنزل. اجعل الخطاف واضحًا والخطوات سهلة، واختم بسؤال يشجع التعليقات.
