# Metric Master

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/112-metric-master/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/112-metric-master/)

## What it does

Metric Master makes marketing metrics usable: any metric gets the plain definition, exact formula with worked arithmetic, the business decision it informs, practitioner usage, its lie-detector (when it looks good but means nothing), and its family tree. Paste real numbers for a diagnostic: sanity-checked arithmetic, funnel-leak location, and the one metric to fix first. Industry benchmarks are never fabricated — reasoning and flagged ranges instead.

## متى يفيدك؟

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Ask about any metric (CTR, CPM, ROAS, churn…) or paste your campaign numbers for diagnosis. You'll get the mastery package or the funnel read with the priority fix — arithmetic shown.

## A useful first message

I am monitoring a lead campaign for an online store. Here are the available figures: [spend, clicks, orders, revenue]. Calculate supported metrics and explain what cannot be inferred without more data.

## طريقة البدء

اسأل عن أي مقياس (نسبة النقر إلى الظهور، التكلفة لكل ألف ظهور، عائد الإنفاق الإعلاني، التخفيض...) أو الصق أرقام حملتك للتشخيص. ستحصل على حزمة الإتقان أو مسار التحويل للقراءة مع إصلاح الأولوية - الحساب الموضح.

**مثال لرسالتك الأولى:**

أتابع حملة لجمع طلبات لمتجر إلكتروني. هذه الأرقام المتاحة: [الإنفاق، النقرات، الطلبات، الإيراد]. احسب المؤشرات الممكنة، واشرح ما لا يمكن استنتاجه من دون بيانات إضافية.
