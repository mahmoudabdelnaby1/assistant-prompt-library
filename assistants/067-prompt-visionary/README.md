**Category:** Research & Analysis
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/067-prompt-visionary/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/067-prompt-visionary/)

## What it does

Prompt Visionary is a prompt-engineering research lab: it explains why techniques work at the mechanism level, names reusable techniques (including novel syntheses with failure conditions), demonstrates them with before→after examples in your domain, and designs lightweight test protocols so gains are proven rather than assumed. Claims are sorted into durable principles, current practice, and labeled hypotheses.

## متى يفيدك؟

Prompt Visionary هو مختبر أبحاث هندسي سريع: فهو يشرح سبب عمل التقنيات على مستوى الآلية، ويسمي التقنيات القابلة لإعادة الاستخدام (بما في ذلك التوليفات الجديدة مع ظروف الفشل)، ويوضحها بأمثلة قبل → بعد في مجالك، ويصمم بروتوكولات اختبار خفيفة الوزن بحيث يتم إثبات المكاسب بدلاً من افتراضها. يتم تصنيف البرومبتات إلى مبادئ دائمة، وممارسات حالية، وفرضيات مصنفة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Ask a prompt-engineering question, paste a prompt for mechanism-level analysis, or request a new technique. You'll get the why, the named method, a worked example, and a test you can run yourself.

## A useful first message

Design a prompt that makes a chat model turn customer-interview notes into recurring themes and improvement opportunities. Include input fields and safeguards against fabricated quotes or conclusions.

## طريقة البدء

اطرح سؤالاً هندسيًا فوريًا، أو الصق موجهًا للتحليل على مستوى الآلية، أو اطلب تقنية جديدة. ستحصل على السبب والطريقة المسماة ومثال عملي واختبار يمكنك إجراؤه بنفسك.

**مثال لرسالتك الأولى:**

صمّم برومبتًا يجعل نموذج محادثة يحوّل ملاحظات مقابلات العملاء إلى موضوعات متكررة وفرص تحسين. أضف خانات للبيانات وقواعد تمنع اختلاق اقتباسات أو استنتاجات.
