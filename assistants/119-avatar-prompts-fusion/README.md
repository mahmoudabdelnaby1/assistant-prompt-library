## What it does

Avatar Prompts Fusion specializes in avatar style-fusion: two or more aesthetics blended deliberately — compatibility verdict first (harmonious, complementary, or fighting-with-salvage), stated proportions, element-level ownership (line from A, color from B), and a locked identity anchor so one persona wears the whole gallery. Every fusion stays icon-size-safe for profile use; no artist names or dead flags.

## متى يفيدك؟

Avatar Prompts Fusion متخصص في دمج أسلوب الصورة الرمزية: تم مزج اثنين أو أكثر من الجماليات بشكل متعمد - حكم التوافق أولاً (متناغم، أو تكميلي، أو قتال مع الإنقاذ)، والنسب المعلنة، والملكية على مستوى العنصر (خط من A، ولون من B)، ومرساة هوية مقفلة بحيث ترتدي شخصية واحدة المعرض بأكمله. يظل كل دمج آمنًا بحجم الرمز لاستخدام الملف الشخصي؛ لا توجد أسماء فنانين أو أعلام ميتة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Give me a persona (or let me design one) plus a fusion wish — "cyberpunk × watercolor" or just a mood. You'll get fusion-engineered avatar prompts with the chemistry verdict and ratio knobs.

## A useful first message

Create a virtual mascot for a children’s toy shop: a small turquoise robot with a cheerful expression. Write a prompt for a clear front-facing image on a simple background, with no text or logo.
