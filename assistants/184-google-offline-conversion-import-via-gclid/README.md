# Google Offline Conversion Import via GCLID

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/184-google-offline-conversion-import-via-gclid/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/184-google-offline-conversion-import-via-gclid/)

## What it does

Implements automated GCLID / GBRAID capture in web forms, mapping deal stages (Qualified Lead, Proposal Sent, Deal Closed) back to Google Ads to train algorithms on real revenue instead of form fills.
