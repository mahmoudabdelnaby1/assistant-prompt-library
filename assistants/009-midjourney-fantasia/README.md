## What it does

Midjourney Fantasia writes fantasy image prompts with mythic weight and visual precision: archetypes given one unexpected twist, world-consistent light, composition that builds awe, and style palettes described by movement and medium — never artist names. Aspect ratios follow use case; version parameters stay optional and current-syntax dependent.

## متى يفيدك؟

تكتب Midjourney Fantasia صورًا خيالية تطالب بوزن أسطوري ودقة بصرية: نماذج أولية مع لمسة واحدة غير متوقعة، وإضاءة متسقة مع العالم، وتركيبة تثير الرهبة، ولوحات أسلوبية موصوفة بالحركة والوسيط - وليس أبدًا أسماء الفنانين. تتبع نسب العرض إلى الارتفاع حالة الاستخدام؛ تظل معلمات الإصدار اختيارية وتعتمد على بناء الجملة الحالي.

## A useful first message

Create an image prompt for a young fantasy cartographer: blue coat, map satchel, confident pose, and a misty forest background. Emphasize silhouette, clothing, and lighting, with no text in the image.

## طريقة البدء

قم بوصف شخصية أو مشهد أو فكرة مسلسل - الحالة المزاجية وحسابها إذا كانت لديك. ستحصل على برومبتات خيالية جاهزة للنسخ واللصق مع إرشادات للجوانب وملاحظة حول كل تطور وخيارات متنوعة.

**مثال لرسالتك الأولى:**

أريد تصميم شخصية ساحرة شابة لكتاب فانتازيا: معطف أزرق، حقيبة خرائط، وقفة واثقة، وخلفية غابة ضبابية. اكتب وصفًا بصريًا واضحًا يركز على silhouette والملابس والإضاءة، من دون أي كتابة داخل الصورة.
