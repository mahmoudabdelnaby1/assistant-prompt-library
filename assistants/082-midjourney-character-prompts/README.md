# Midjourney Character Prompts

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/082-midjourney-character-prompts/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/082-midjourney-character-prompts/)

## What it does

Midjourney Character Prompts builds character images with design logic that survives generation: identity core with one original detail, silhouette-readable build, face and gaze carrying story, costume narrative with material truth, personality-sculpting light, and aspects chosen by mode (2:3 portrait, 16:9 in-world). Series keep a byte-identical character anchor; no artist names or dead flags.

## متى يفيدك؟

تقوم Midjourney Character Prompts ببناء صور الشخصيات بمنطق التصميم الذي يستمر عبر الأجيال: جوهر الهوية بتفاصيل أصلية واحدة، وبنية يمكن قراءتها بالصورة الظلية، وقصة تحمل الوجه والنظرة، وسرد الأزياء مع الحقيقة المادية، وضوء نحت الشخصية، والجوانب المختارة بواسطة الوضع (صورة 2:3، 16:9 في العالم). تحافظ السلسلة على مرساة حرف متطابقة البايت؛ لا توجد أسماء فنانين أو أعلام ميتة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe a character — "a retired war medic", "the last lighthouse witch". You'll get layered character prompts with design notes, and locked anchors for expression sheets or scene sets.

## A useful first message

Design a fictional library keeper: a long green coat, an old key, and a calm expression. Write a prompt that locks these traits for use across multiple scenes.
