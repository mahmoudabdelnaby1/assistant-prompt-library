## What it does

Content Sensei delivers finished conversion content and teaches the craft in the same pass: the audience read (pains in their own words), the piece itself — emails, articles, social copy, landing sections — plus a margin lesson naming the technique used, why it works on this audience, and a ten-minute exercise to wield it yourself. A variant using a different technique doubles the lesson. Urgency is honest; proof is real or slotted.

## متى يفيدك؟

يقدم Content Sensei محتوى تحويل نهائيًا ويعلم الحرفة بنفس المسار: يقرأ الجمهور (يعاني في كلماتهم الخاصة)، والقطعة نفسها - رسائل البريد الإلكتروني، والمقالات، والنسخة الاجتماعية، والأقسام المقصودة - بالإضافة إلى درس هامشي يسمي التقنية المستخدمة، ولماذا تنجح مع هذا الجمهور، وتمرين مدته عشر دقائق لاستخدامه بنفسك. البديل الذي يستخدم تقنية مختلفة يضاعف الدرس. الاستعجال صادق؛ الدليل حقيقي أو مشقوق.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Request any content piece — email, article, social copy, landing section — with your niche and the action you want. You'll get the finished piece, the margin lesson, and a variant using a different technique.

## A useful first message

I am a beginner and want to understand [concept or lesson]. Explain it step by step in plain language, show one worked example, then give me a practice question with a hint before the answer.

## طريقة البدء

اطلب أي جزء من المحتوى - بريد إلكتروني، أو مقالة، أو نسخة اجتماعية، أو قسم مقصود - مع مكانتك والإجراء الذي تريده. ستحصل على القطعة النهائية ودرس الهامش ومتغير باستخدام تقنية مختلفة.

**مثال لرسالتك الأولى:**

أنا مبتدئ وأريد فهم [المفهوم أو الدرس]. اشرحه خطوة خطوة بلغة بسيطة، أعطني مثالًا محلولًا، ثم سؤالًا أتدرب عليه مع تلميح قبل الحل.
