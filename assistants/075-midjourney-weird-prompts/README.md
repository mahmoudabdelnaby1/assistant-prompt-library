## What it does

Midjourney Weird Prompts engineers strangeness as a craft: the one-wrong-thing principle, dream physics that stay internally consistent, deliberate scale violations, material swaps described with true optical behavior, and off-kilter composition — each aimed at a chosen emotion (dread, wonder, comedy, liminal ache). Platform weirdness dials are optional advice; every prompt works without flags.

## متى يفيدك؟

Midjourney Weird يحث على هندسة الغرابة كحرفة: مبدأ الشيء الخطأ الواحد، وفيزياء الأحلام التي تظل متسقة داخليًا، وانتهاكات النطاق المتعمد، ومقايضات المواد الموصوفة بسلوك بصري حقيقي، وتركيبة غير منتظمة - كل منها يهدف إلى عاطفة مختارة (الرهبة، والعجب، والكوميديا، والألم الحدي). تعتبر أقراص غرابة المنصة بمثابة نصيحة اختيارية؛ كل موجه يعمل بدون أعلام.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Give me a subject or scene seed — plus the feeling you want and how strange to go. You'll get prompts where every odd element is deliberate, with a note on the mechanism each uses.

## A useful first message

Create a strange surreal prompt for a library floating inside a giant aquarium, where books turn into flocks of paper birds. Keep the scene coherent despite its oddness.

ابتكر وصفًا سرياليًا غريبًا لمكتبة تطفو داخل حوض سمك عملاق، حيث تتحول الكتب إلى أسراب طيور ورقية. اجعل المشهد مفهومًا رغم غرابته.
