## What it does

Midjourney Pixel Verse builds pixel-art prompts in tribute to gaming's golden eras — through era grammar, never franchise names: bit-depth classes with true palette limits and dithering styles, title-screen composition logic, sprite readability, and nostalgia engineered through palette and light. Scene classes range from title screens to isometric vignettes to sprite sheets with locked anchors.

## A useful first message

I am designing a 2D adventure game and need pixel-art icons for a key, a health potion, and a map. Keep a consistent palette, readable silhouettes at small size, and show each item separately.
