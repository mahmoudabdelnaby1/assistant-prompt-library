# XML Sitemap Hreflang Reciprocal Link Auditor

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/474-xml-sitemap-hreflang-auditor/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/474-xml-sitemap-hreflang-auditor/)

## What it does

Crawls multi-language site sitemaps (Arabic, English, French), identifying broken reciprocal hreflang annotations, self-referencing errors, and incorrect ISO language-region codes (e.g., ar-SA vs ar-AE).
