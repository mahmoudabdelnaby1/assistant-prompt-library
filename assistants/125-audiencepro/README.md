## What it does

AudiencePro builds audience strategy segmentation-first: the demand landscape mapped by buying logic, three to five coherent segments with jobs-to-be-done and honest size-estimation methods, a visible scorecard, the beachhead pick with expansion sequence and triggers, the priority segment's full demographic-plus-psychographic portrait, secondary briefs, and a message-implications table. Market percentages are never fabricated — sizing is delivered as logic you run on real data.

## متى يفيدك؟

تقوم AudiencePro ببناء تقسيم استراتيجية الجمهور أولاً: مخطط الطلب عن طريق منطق الشراء، وثلاثة إلى خمسة شرائح متماسكة مع المهام التي سيتم تنفيذها وطرق تقدير الحجم الصادقة، وبطاقة الأداء المرئية، واختيار رأس الجسر مع تسلسل التوسع والمشغلات، والصورة الديموغرافية والنفسية الكاملة للقطاع ذي الأولوية، والموجزات الثانوية، وجدول آثار الرسالة. لا يتم اختلاق النسب المئوية للسوق أبدًا - يتم تقديم الحجم كمنطق تقوم بتشغيله على بيانات حقيقية.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your business — existing-customer patterns help if you have them. You'll get the segment architecture, scorecard, beachhead recommendation, priority portrait, and the message table your copywriter can use directly.

## A useful first message

I am launching a meal-delivery service in a new city. Segment potential customers by needs and buying behavior, prioritize which groups to test first, and identify missing data.

## طريقة البدء

قم بوصف عملك – تساعد أنماط العملاء الحاليين إذا كان لديك تلك الأنماط. ستحصل على بنية المقطع، وبطاقة الأداء، وتوصية رأس الجسر، وصورة الأولوية، وجدول الرسائل الذي يمكن لكاتب الإعلانات استخدامه مباشرة.

**مثال لرسالتك الأولى:**

أطلق خدمة توصيل وجبات في مدينة جديدة. قسّم العملاء المحتملين وفق احتياجاتهم وسلوك الشراء، ورتّب الشرائح التي تستحق الاختبار أولًا مع توضيح البيانات الناقصة.
