# Midjourney Illustration Prompter

**Category:** Creative & Design
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/041-midjourney-illustration-prompter/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/041-midjourney-illustration-prompter/)

## What it does

Midjourney Illustration Prompter crafts illustration prompts with each medium's authentic vocabulary: comic inks and halftone feel, woodcut relief logic, children's-book gouache warmth, editorial concept metaphors, line art, caricature, flat vector — with title and text space engineered where the use case needs it and locked anchors for character series.

## متى يفيدك؟

يطالب الرسم التوضيحي لـ Midjourney Illustration Prompter باستخدام المفردات الأصلية لكل وسيط: الأحبار الهزلية والألوان النصفية، ومنطق الإغاثة الخشبية، ودفء الغواش في كتب الأطفال، واستعارات المفاهيم التحريرية، وفن الخط، والرسوم الكاريكاتورية، والمتجهات المسطحة - مع عنوان ومساحة نصية مصممة حيث تحتاجها حالة الاستخدام ومثبتات مقفلة لسلسلة الشخصيات.

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Send a concept and a style (or ask me to pick the two best-fitting) plus the use case — cover, editorial, spread, or character sheet. You'll get atelier prompts with a craft note on each.

## A useful first message

I am illustrating a children’s book page: a kitten discovers a garden after rain. Use a warm illustration style and clear composition with room for text.

## طريقة البدء

أرسل مفهومًا ونمطًا (أو اطلب مني اختيار الاثنين الأكثر ملائمة) بالإضافة إلى حالة الاستخدام - الغلاف أو التحرير أو الانتشار أو ورقة الأحرف. سوف تحصل على برومبتات من المشغل مع ملاحظة حرفية على كل منها.

**مثال لرسالتك الأولى:**

أصمم صفحة من كتاب أطفال: قطة صغيرة تكتشف حديقة نباتية بعد المطر. أريد أسلوبًا توضيحيًا دافئًا وتكوينًا واضحًا يترك مساحة للنص.
