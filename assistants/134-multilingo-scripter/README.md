# MultiLingo Scripter

**Category:** Writing & Storytelling
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/134-multilingo-scripter/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/134-multilingo-scripter/)

## What it does

MultiLingo Scripter writes short-video scripts that get reborn per language, not translated: one shared strategy skeleton (hook type, beats, payoff, end-behavior) rendered natively in each requested language — its own rhythm, idioms born there, humor mechanics rebuilt, cultural references swapped — with timing math computed per language so every version fits the duration. Versions stay strategically parallel for cross-market comparison.

## متى يفيدك؟

يكتب MultiLingo Scripter نصوص فيديو قصيرة تولد من جديد لكل لغة، غير مترجمة: هيكل استراتيجي مشترك واحد (نوع الخطاف، الإيقاعات، المكافأة، السلوك النهائي) يتم تقديمه محليًا في كل لغة مطلوبة - إيقاعها الخاص، والتعابير التي ولدت هناك، وإعادة بناء آليات الفكاهة، وتبديل المراجع الثقافية - مع حساب التوقيت الحسابي لكل لغة بحيث تناسب كل نسخة المدة. تظل الإصدارات متوازية استراتيجيًا للمقارنة بين الأسواق.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send subject, audience, duration, platform — and the languages you need. Each version arrives natively engineered with its word budget, beat timings, caption, and a cross-market note on what changed and why.

## A useful first message

Write a 30-second vertical video script for a new Cairo café: a strong opening hook, three short shots, simple voice-over, and an invitation to visit. Use natural Egyptian Arabic and do not add an unverified offer or price.

## طريقة البدء

أرسل الموضوع والجمهور والمدة والنظام الأساسي - واللغات التي تحتاجها. يصل كل إصدار مصممًا محليًا بميزانية الكلمات، وتوقيت الإيقاع، والتسمية التوضيحية، ومذكرة عبر السوق حول ما تغير ولماذا.

**مثال لرسالتك الأولى:**

اكتب سيناريو فيديو عمودي مدته 30 ثانية لمقهى جديد في القاهرة: افتتاحية تشد الانتباه، 3 لقطات قصيرة، تعليق صوتي بسيط، ودعوة لزيارة المكان. اجعل اللغة مصرية طبيعية ولا تضف عرضًا أو سعرًا غير مؤكد.
