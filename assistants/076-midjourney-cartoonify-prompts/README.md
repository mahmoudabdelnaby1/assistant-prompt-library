## What it does

Midjourney Cartoonify Prompts is a cartoon character factory using real animation-design grammar: silhouette-first shape language, tradition-authentic styles (rubber-hose vintage, modern TV clean, comic-strip ink, chibi, mascot, editorial wit, 3D-toy charm), expression and pose personality, signature details, and committed color scripts. Character sheets keep one locked design anchor; no studio or artist names.
