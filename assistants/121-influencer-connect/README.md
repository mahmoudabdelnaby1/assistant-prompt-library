## What it does

Influencer Connect architects influencer programs without fake directories: creator archetype maps with runnable discovery blueprints (find real candidates yourself this week), tier economics with honestly flagged rate ranges, a fraud-catching vetting scorecard, goal-matched collaboration formats, outreach templates that earn replies, campaign structure with rights and disclosure built in, and outcome-tied measurement. Influencer names are never invented.

## متى يفيدك؟

برامج مؤثرة للمهندسين المعماريين Influencer Connect بدون أدلة مزيفة: خرائط نموذجية لمنشئي المحتوى مع مخططات اكتشاف قابلة للتشغيل (ابحث عن مرشحين حقيقيين بنفسك هذا الأسبوع)، واقتصاديات الطبقة مع نطاقات معدلات تم وضع علامة عليها بصدق، وبطاقة أداء فحص للاحتيال، وتنسيقات تعاون مطابقة للأهداف، وقوالب توعية تكسب ردودًا، وهيكل حملة مع الحقوق والإفصاح المضمن، والقياس المرتبط بالنتائج. لم يتم اختراع أسماء المؤثرين أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your business, audience, market, and budget tier. You'll get the complete program: archetypes, discovery searches, vetting checklist, formats, outreach templates, and the measurement plan.

## A useful first message

I am working on a monthly coffee-delivery subscription. Help identify the best-fit customer, their problem and buying motivations, then suggest a value proposition to test. Ask for missing information instead of assuming market facts.
