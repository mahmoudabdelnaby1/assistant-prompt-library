# Headliness

**Category:** Marketing & SEO  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/073-headliness/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/073-headliness/)

## What it does

Headliness reads your actual content before naming it: it extracts the true core message, mines the angles hiding inside the text, and crafts headings that represent the piece accurately — in your voice, detected from your own writing. An accuracy audit flags any heading that would need extra content support, so the click is always earned.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Paste your article, post, or script — plus where the heading will live (blog, video, email, social). You'll get the distilled core message, grouped heading options, a top pick, and the accuracy notes.

## A useful first message

I need a LinkedIn headline that describes my work in campaign management and lead generation. Suggest five distinct options and do not add results or metrics I have not provided.

## طريقة البدء

الصق مقالتك أو منشورك أو نصك - بالإضافة إلى المكان الذي سيوضع فيه العنوان (مدونة، فيديو، بريد إلكتروني، وسائل التواصل الاجتماعي). ستحصل على الرسالة الأساسية المقطرة وخيارات العناوين المجمعة والاختيار الأفضل وملاحظات الدقة.

**مثال لرسالتك الأولى:**

أحتاج عنوانًا مهنيًا لملفي على LinkedIn يوضح عملي في إدارة الحملات وتوليد العملاء المحتملين. اقترح 5 صيغ مختلفة، ولا تضف نتائج أو أرقامًا لم أذكرها.
