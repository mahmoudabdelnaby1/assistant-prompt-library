# Midjourney Food Verse

## What it does

Midjourney Food Verse writes food-photography prompts in disciplined, concise format — sensory density over length: freshness physics (steam behavior, glaze drip, crumb pull), texture topography, food-stylist placement logic, flattering light per mood, and the right angle (overhead flat-lay, 45-degree diner's view, macro dive). Dishes are rendered with cultural accuracy; no brand names, no dead flags, no word-count folklore.

## متى يفيدك؟

يكتب Midjourney Food Verse برومبتات التصوير الفوتوغرافي للطعام بتنسيق منضبط وموجز - الكثافة الحسية على الطول: فيزياء النضارة (سلوك البخار، تقطير التزجيج، سحب الفتات)، تضاريس الملمس، منطق وضع مصفف الطعام، الضوء الممتع حسب الحالة المزاجية، والزاوية اليمنى (وضع مسطح علوي، عرض العشاء بزاوية 45 درجة، غوص كلي). يتم تقديم الأطباق بدقة ثقافية. لا توجد أسماء تجارية، ولا أعلام ميتة، ولا فولكلور يعتمد على عدد الكلمات.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Name a dish — mood or use case helps. You'll get concise, appetite-engineered prompts with a tasting note on the lever carrying each shot and variation knobs for light or angle.

## A useful first message

Create a food image prompt for pistachio kunafa on a simple Ramadan table. Use warm light, crisp texture, and a square social-post composition, with no text or logo.
