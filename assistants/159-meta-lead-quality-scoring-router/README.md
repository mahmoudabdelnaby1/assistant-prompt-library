# Meta Lead Quality Scoring Router

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/159-meta-lead-quality-scoring-router/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/159-meta-lead-quality-scoring-router/)

## What it does

Connects CRM lead statuses (Qualified, Demo Completed, Deal Closed) back to Meta via Offline Conversions API, training the algorithm to target high-intent decision-makers instead of low-quality submissions.
