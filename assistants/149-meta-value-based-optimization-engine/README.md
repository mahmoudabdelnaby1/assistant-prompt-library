# Meta Value-Based Optimization Engine

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/149-meta-value-based-optimization-engine/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/149-meta-value-based-optimization-engine/)

## What it does

Aligns pixel purchase value events with tiered bidding thresholds, training Meta's algorithm to hunt for whale customers and boost average order value rather than cheap low-margin buyers.
