# Engage Script Master

**Category:** Writing & Storytelling
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/086-engage-script-master/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/086-engage-script-master/)

## What it does

Engage Script Master writes video scripts where product promotion lives inside genuinely valuable content: the value spine stands alone, the product enters through a named integration pattern (natural tool, payoff demo, honest companion, contrast proof, story embed), sponsorship disclosure is placed as a trust beat, and the CTA lands at peak receptivity. Claims stay within the product's real capabilities.

## متى يفيدك؟

يقوم Engage Script Master بكتابة نصوص فيديو حيث يوجد الترويج للمنتج داخل محتوى ذي قيمة حقيقية: عمود القيمة يقف بمفرده، ويدخل المنتج من خلال نمط تكامل مسمى (أداة طبيعية، عرض توضيحي للمكافأة، رفيق صادق، دليل على التباين، تضمين القصة)، يتم وضع الكشف عن الرعاية باعتباره فوزًا للثقة، وتصل CTA إلى ذروة التقبل. تبقى البرومبتات ضمن القدرات الحقيقية للمنتج.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send your video topic and your product — plus a sample of your voice if you have one. You'll get the complete script with exact spoken lines, visual directions, disclosure, CTA timing, and title/thumbnail direction.

## A useful first message

Write a 30-second vertical video script for a new Cairo café: a strong opening hook, three short shots, simple voice-over, and an invitation to visit. Use natural Egyptian Arabic and do not add an unverified offer or price.

## طريقة البدء

أرسل موضوع الفيديو الخاص بك والمنتج الخاص بك - بالإضافة إلى عينة من صوتك إذا كان لديك واحدة. ستحصل على النص الكامل مع الخطوط المنطوقة الدقيقة، والتوجيهات المرئية، والإفصاح، وتوقيت CTA، واتجاه العنوان/الصورة المصغرة.

**مثال لرسالتك الأولى:**

اكتب سيناريو فيديو عمودي مدته 30 ثانية لمقهى جديد في القاهرة: افتتاحية تشد الانتباه، 3 لقطات قصيرة، تعليق صوتي بسيط، ودعوة لزيارة المكان. اجعل اللغة مصرية طبيعية ولا تضف عرضًا أو سعرًا غير مؤكد.
