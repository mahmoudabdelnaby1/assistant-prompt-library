## What it does

Seasoned Product Manager generates the PM document your context actually needs — PRD, project plan, or progress report — auto-detected and structured to professional standards: prioritized user stories with testable acceptance criteria, non-goals, risk registers with pre-mortems, honest status headlines, and explicit asks. Unknown data becomes specific [TODO] slots with guidance; dates, metrics, and names are never invented.

## متى يفيدك؟

يقوم مدير المنتج المتمرس بإنشاء مستند إدارة المشاريع الذي يحتاجه سياقك فعليًا - PRD أو خطة المشروع أو تقرير التقدم - يتم اكتشافه تلقائيًا وتنظيمه وفقًا للمعايير المهنية: قصص المستخدمين ذات الأولوية مع معايير القبول القابلة للاختبار، وغير الأهداف، وسجلات المخاطر مع ما قبل الوفاة، وعناوين الحالة الصادقة، والطلبات الصريحة. تصبح البيانات غير المعروفة فتحات [TODO] محددة مع التوجيه؛ لم يتم اختراع التواريخ والمقاييس والأسماء أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your product or project at any roughness — even three lines. I'll detect the right document and write it complete, with visible TODO slots where your real data goes and the exec questions it will face pre-answered.

## A useful first message

I am improving checkout for an online store. Organize the problems and hypotheses, propose one measurable experiment, and list metrics and risks before starting.

## طريقة البدء

قم بوصف منتجك أو مشروعك بأي شكل من الأشكال - حتى ثلاثة أسطر. سأكتشف المستند الصحيح وأكتبه كاملاً، مع فتحات المهام المرئية التي تذهب إليها بياناتك الحقيقية والأسئلة التنفيذية التي ستواجهها والتي سيتم الإجابة عليها مسبقًا.

**مثال لرسالتك الأولى:**

أعمل على تحسين صفحة الدفع في متجر إلكتروني. رتّب المشكلات والفرضيات، واقترح تجربة واحدة قابلة للقياس، واذكر المؤشرات والمخاطر قبل البدء.
