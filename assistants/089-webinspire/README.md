# WebInspire

**Category:** Creative & Design
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/089-webinspire/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/089-webinspire/)

## What it does

WebInspire turns a business description into a buildable design vision: the visitor's mindset decoded, three genuinely distinct style directions (mood, palette with roles, type character, imagery treatment), a section-by-section homepage blueprint with each section's job, UX patterns mapped to your stated priorities (friendliness, collaboration, productivity, conversion), interaction philosophy, and accessibility conscience — with reasoning on every choice.

## متى يفيدك؟

يقوم WebInspire بتحويل وصف الأعمال إلى رؤية تصميمية قابلة للبناء: فك تشفير عقلية الزائر، وثلاثة اتجاهات نمطية متميزة حقًا (الحالة المزاجية، ولوحة الألوان مع الأدوار، ونوع الشخصية، ومعالجة الصور)، ومخطط الصفحة الرئيسية لكل قسم على حدة مع وظيفة كل قسم، وأنماط تجربة المستخدم المعينة لأولوياتك المعلنة (الود، والتعاون، والإنتاجية، والتحويل)، وفلسفة التفاعل، وضمير إمكانية الوصول - مع التفكير في كل اختيار.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your business and what the site must do. You'll get the design vision document — three directions, layout blueprint, priority-matched UX patterns — and my recommended pick with what to borrow from the others.

## A useful first message

I need a simple landing page for a web-design service. The audience is small-business owners and the goal is booking a consultation. Suggest a mobile-friendly structure and starter content, and ask for missing brand details.

## طريقة البدء

قم بوصف عملك وما يجب أن يفعله الموقع. ستحصل على وثيقة رؤية التصميم - ثلاثة اتجاهات، ومخطط تخطيط، وأنماط تجربة المستخدم المطابقة للأولوية - واختياري الموصى به مع ما يمكن استعارته من الآخرين.

**مثال لرسالتك الأولى:**

أريد صفحة تعريف بسيطة لخدمة تصميم مواقع. الجمهور أصحاب الأعمال الصغيرة والهدف حجز استشارة. اقترح هيكلًا ومحتوى أوليًا متجاوبًا مع الهاتف، واسألني عن الهوية البصرية الناقصة.
