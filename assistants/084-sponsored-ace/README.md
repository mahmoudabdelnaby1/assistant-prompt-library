# Sponsored Ace

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/084-sponsored-ace/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/084-sponsored-ace/)

## What it does

Sponsored Ace turns one ad concept into multi-platform campaigns (Facebook, Instagram, LinkedIn): each network gets a distinct funnel role with reasoning — including platforms deliberately skipped — plus layered audience architecture, test-then-scale budget gates, platform-native creative packages in your market's language, measurement tied to the objective, and compliance notes. Benchmarks arrive as flagged ranges; no fabricated precision.

## متى يفيدك؟

يقوم Sponsored Ace بتحويل مفهوم إعلان واحد إلى حملات متعددة المنصات (Facebook وInstagram وLinkedIn): تحصل كل شبكة على دور مسار تحويلي مميز مع المنطق - بما في ذلك المنصات التي تم تخطيها عمدًا - بالإضافة إلى بنية الجمهور متعددة الطبقات، وبوابات الميزانية التي يتم اختبارها ثم توسيع نطاقها، والحزم الإبداعية الأصلية للنظام الأساسي بلغة السوق الخاصة بك، والقياس المرتبط بالهدف، وملاحظات الامتثال. تصل المعايير كنطاقات تم وضع علامة عليها؛ لا دقة ملفقة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send the ad idea or concept — plus market, language, and budget if known. You'll get the campaign document: platform roles, audiences, budget logic, native creative packages, and the launch checklist.

## A useful first message

I want to promote a free workshop for store owners on Facebook, Instagram, and LinkedIn. Recommend each platform’s role, ad message, test budget, and success metric.

## طريقة البدء

أرسل فكرة الإعلان أو مفهومه - بالإضافة إلى السوق واللغة والميزانية إذا كانت معروفة. ستحصل على مستند الحملة: أدوار النظام الأساسي، والجماهير، ومنطق الميزانية، وحزم التصميمات الأصلية، وقائمة التحقق من الإطلاق.

**مثال لرسالتك الأولى:**

أريد الترويج لورشة مجانية لأصحاب المتاجر على Facebook وInstagram وLinkedIn. اقترح دور كل منصة ورسالة الإعلان والميزانية التجريبية ومؤشر النجاح.
