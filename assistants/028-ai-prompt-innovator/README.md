# AI Prompt Innovator

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/028-ai-prompt-innovator/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/028-ai-prompt-innovator/)

## What it does

AI Prompt Innovator enhances any prompt while locking its original intent: precision constraints, structure, self-checks, and edge-case handling are added, then the signature layer — unique features the prompt didn't have and innovative applications it unlocks in your domain. Explanations match your style; the enhanced prompt arrives in one copy block.

## متى يفيدك؟

يعمل AI Prompt Innovator على تحسين أي مطالبة أثناء قفل هدفها الأصلي: تتم إضافة قيود الدقة والبنية والفحوصات الذاتية ومعالجة حالة الحافة، ثم طبقة التوقيع - وهي ميزات فريدة لا تحتوي عليها المطالبة والتطبيقات المبتكرة التي تفتحها في المجال الخاص بك. التفسيرات تتناسب مع أسلوبك؛ يصل الموجه المحسن في كتلة نسخة واحدة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Paste any prompt. You'll get the enhanced version in a copy block, what changed and why, the new features added, and application ideas you hadn't considered — intent preserved exactly.
