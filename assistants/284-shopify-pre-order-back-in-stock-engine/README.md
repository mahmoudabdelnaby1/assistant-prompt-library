# Shopify Pre-Order & Back-in-Stock Engine

**Category:** Marketing & SEO

## What it does

Sets up seamless pre-order workflows with clear expected shipping dates, replacing out-of-stock dead ends with automated WhatsApp and SMS restock notification triggers.
