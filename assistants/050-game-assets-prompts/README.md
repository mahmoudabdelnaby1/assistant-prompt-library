## What it does

Game Assets Prompts converts plain dev-speak into concept-art briefs: characters, creatures, environments, props, and UI elements delivered as production-useful views (hero shots, turnarounds, prop sheets, expression sets) under one locked style anchor so the whole game world stays coherent. Silhouette readability and material storytelling come first; franchise names are never used.

## متى يفيدك؟

تعمل برومبتات أصول اللعبة على تحويل كلام التطوير البسيط إلى ملخصات فنية مفاهيمية: الشخصيات، والمخلوقات، والبيئات، والدعائم، وعناصر واجهة المستخدم التي يتم تقديمها كعروض مفيدة للإنتاج (لقطات البطل، والتحولات، وأوراق الدعائم، ومجموعات التعبير) تحت مرساة نمط مقفل واحد بحيث يظل عالم اللعبة بأكمله متماسكًا. سهولة القراءة والسرد المادي تأتي في المقام الأول؛ لا يتم استخدام أسماء الامتياز أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Describe the asset in plain words — what it is and what it's for in-game. You'll get production-ready prompts with the style anchor, view type matched to your pipeline stage, and variant knobs.

## A useful first message

I am designing a 2D adventure game and need pixel-art icons for a key, a health potion, and a map. Keep a consistent palette, readable silhouettes at small size, and show each item separately.

## طريقة البدء

قم بوصف الأصل بكلمات واضحة - ما هو وما الغرض منه داخل اللعبة. ستحصل على برومبتات جاهزة للإنتاج من خلال مرساة النمط، ونوع العرض المطابق لمرحلة خط الأنابيب، والمقابض المتغيرة.

**مثال لرسالتك الأولى:**

أصمم لعبة مغامرة ثنائية الأبعاد وأحتاج مجموعة أيقونات pixel art: مفتاح، جرعة علاج، وخريطة. حافظ على لوحة ألوان متناسقة وحجم واضح عند التصغير، واعرض كل عنصر منفصلًا.
