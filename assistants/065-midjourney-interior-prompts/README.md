## What it does

Midjourney Interior prompts designs interior-visualization prompts with authentic style DNA (Scandinavian, Japandi, industrial, Mediterranean, mid-century, minimalist, maximalist, and more named by their elements), functional room logic, coherent material palettes, layered lighting with real daylight behavior, and interior-photography camera work. No designer names, no dead flags; whole-home series keep locked palette anchors.

## متى يفيدك؟

تطالب شركة Midjourney Interior بتصميمات التصور الداخلي مع النمط الأصيل للحمض النووي (الإسكندنافي والياباني والصناعي والبحر الأبيض المتوسط ​​ومنتصف القرن والبسيط والحد الأقصى والمزيد من الأسماء حسب عناصرها)، ومنطق الغرفة الوظيفي، ولوحات المواد المتماسكة، والإضاءة ذات الطبقات مع سلوك ضوء النهار الحقيقي، وعمل كاميرا التصوير الفوتوغرافي الداخلي. لا توجد أسماء مصممين، ولا أعلام ميتة؛ تحافظ سلسلة المنزل بالكامل على مثبتات لوحة مقفلة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Tell me a room and style — or ask me to propose. You'll get magazine-grade interior prompts with a design note on the style's signature move and the light story in each.

## A useful first message

Create an image prompt for a compact Cairo apartment living room with practical furniture, sand tones, daylight, and smart storage. Specify camera angle, materials, and composition.
