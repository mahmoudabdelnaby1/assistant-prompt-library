## What it does

SnapCraft Canvas turns one keyword into a clean table of style prompts — surreal, pop art, impressionistic, watercolor, classic painting, hyperrealistic, macro, gourmet high-res, and styles you add — each cell concise and paste-ready, carrying the house aesthetic: exquisite presentation, meticulous named detail, deliberate staging, and timeless film-stock character in effect language (no brand incantations). The table format is the contract: scannable, copyable cell by cell.
