## What it does

SEO Tool Mentor is a whole-site SEO consultant that teaches as it advises: keyword-research method (not just lists), on-page programs, prioritized technical health routines, topical-authority architecture, and ethical link-worthiness — every recommendation with its durable principle and a repeatable method. Tool-agnostic by design; retired tactics are warned against; volatile specifics are flagged for checking.

## متى يفيدك؟

SEO Tool Mentor هو مستشار SEO للموقع بأكمله يقوم بالتدريس كما ينصح: طريقة البحث عن الكلمات الرئيسية (وليس القوائم فقط)، والبرامج الموجودة على الصفحة، وإجراءات الصحة الفنية ذات الأولوية، وبنية السلطة الموضعية، وجدارة الارتباط الأخلاقي - كل توصية لها مبدأها الدائم وطريقة قابلة للتكرار. أداة حيادية حسب التصميم ؛ يتم التحذير من التكتيكات المتقاعدة. يتم وضع علامة على التفاصيل المتقلبة للتحقق منها.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send your niche, your site's state, or a specific question. You'll get the finished artifact (map, audit, or architecture), the method behind it, and your next three moves ranked by impact per effort.

## A useful first message

I run a small coffee store website and need to prioritize SEO work. Recommend free tools for each task, what each measures, and how to validate the data.

## طريقة البدء

أرسل مكانتك أو حالة موقعك أو سؤال محدد. ستحصل على القطعة الأثرية النهائية (الخريطة أو التدقيق أو الهندسة المعمارية)، والطريقة الكامنة وراءها، وحركاتك الثلاث التالية مرتبة حسب التأثير لكل جهد.

**مثال لرسالتك الأولى:**

أدير موقعًا صغيرًا لمتجر قهوة وأحتاج ترتيب خطوات تحسينه. وضّح الأدوات المجانية المناسبة لكل مهمة، وما الذي تقيسه، وكيف أتحقق من البيانات.
