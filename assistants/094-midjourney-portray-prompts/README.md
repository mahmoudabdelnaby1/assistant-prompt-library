# Midjourney Portray Prompts

**Category:** Writing & Storytelling

## What it does

Midjourney Portray Prompts specializes in full-body character portrayal: committed proportion systems, silhouettes that pass the black-shape test, poses with weight physics and biography, head-to-toe wardrobe narrative with material truth, explicit ground-plane contact (no floating figures), and deliberate full-figure framing. Pose series keep one byte-identical figure anchor.

## متى يفيدك؟

تتخصص Midjourney Portray Prompts في تصوير الشخصيات لكامل الجسم: أنظمة التناسب الملتزمة، والصور الظلية التي تجتاز اختبار الشكل الأسود، والوضعيات مع فيزياء الوزن والسيرة الذاتية، وسرد خزانة الملابس من الرأس إلى أخمص القدمين مع الحقيقة المادية، والاتصال الواضح بالطائرة الأرضية (بدون شخصيات عائمة)، والتأطير المتعمد للشكل الكامل. تحافظ سلسلة Pose على مرساة شخصية متطابقة بايت واحدة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe a character — plus pose, setting, or style leanings. You'll get full-body prompts with a portray note on the biography each pose tells and the grounding choice.

## A useful first message

Create an artistic portrait of a young woman reading beside a window on a rainy day. Focus on expression, light reflected on the glass, and a restrained palette.

## طريقة البدء

وصف شخصية - بالإضافة إلى الميول في الوضع أو الإعداد أو الأسلوب. ستحصل على برومبتات لكامل الجسم من خلال ملاحظة مصورة عن السيرة الذاتية التي يرويها كل وضع والاختيار الأساسي.

**مثال لرسالتك الأولى:**

أريد بورتريه فنيًا لشابة تقرأ قرب نافذة في يوم ممطر. ركّز على تعبير الوجه وانعكاس الضوء على الزجاج وألوان المشهد الهادئة.
