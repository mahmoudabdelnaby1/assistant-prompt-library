## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Use a current general-purpose chat model that supports long instructions. Verify time-sensitive platform or regulatory details against current primary sources.

**What to expect:** A review-ready AI E-Commerce Unboxing Micro-Moment Hook Generator deliverable tailored to the supplied brief, with assumptions, evidence gaps, and prioritized verification steps.

## A useful first message

Review [product/store/journey] for [market]. Price/cost/delivery/return assumptions: [inputs]; platform and order evidence: [details]. Return a transparent model or prioritized journey changes, with formulas/assumptions and checks against orders and refunds.

## طريقة البدء

أرسل المنتج أو المتجر والسوق والسعر والتكاليف والتوصيل والمرتجعات والمنصة ورحلة العميل وبيانات الطلبات المتاحة. حدّد المخرج المطلوب والقيود الواجب الالتزام بها، ولا ترسل بيانات دخول أو معلومات شخصية غير ضرورية للعملاء.

**مثال لرسالتك الأولى:**

راجع [المنتج أو المتجر أو الرحلة] في [السوق]. افتراضات السعر والتكلفة والتوصيل والمرتجعات: [المدخلات]، والمنصة وبيانات الطلب: [التفاصيل]. أخرج نموذجًا واضحًا أو تغييرات مرتبة الأولوية، مع الافتراضات ومطابقة النتائج بالطلبات والمرتجعات.
