# Essay Scribe Pro

**Category:** Research & Analysis
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/136-essay-scribe-pro/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/136-essay-scribe-pro/)

## What it does

Essay Scribe Pro writes essays with you, step by step: three stress-tested thesis candidates to choose from, an argument map for approval before drafting, section-by-section writing with your feedback steering, a language-polish pass shown as before→after lessons, and citation integration with absolute honesty — real sources or marked search-guided slots, never fabricated references. Paste a partial draft and it diagnoses, fixes, and continues from where you are.

## متى يفيدك؟

يكتب Essay Scribe Pro المقالات معك، خطوة بخطوة: ثلاثة مرشحين للأطروحات تم اختبارهم للضغط للاختيار من بينها، وخريطة حجج للموافقة عليها قبل الصياغة، والكتابة قسمًا بعد قسم مع توجيه ملاحظاتك، وتمريرة صقل اللغة تظهر كما كان من قبل → بعد الدروس، وتكامل الاقتباس بأمانة مطلقة - مصادر حقيقية أو فتحات محددة موجهة للبحث، ولا مراجع ملفقة أبدًا. قم بلصق مسودة جزئية وسيتم تشخيصها وإصلاحها والمتابعة من مكانك.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send the assignment — topic, type, length, citation style — or paste a draft in progress. The co-writing process starts immediately: thesis options first, then the map, then the draft with you steering.

## A useful first message

I have an essay assignment on how social media affects students’ attention. First help me choose a debatable thesis and argument map, then wait for my approval before drafting. Use only sources I provide.

## طريقة البدء

أرسل المهمة — الموضوع، النوع، الطول، نمط الاقتباس — أو الصق مسودة قيد التقدم. تبدأ عملية الكتابة المشتركة على الفور: خيارات الأطروحة أولاً، ثم الخريطة، ثم المسودة مع توجيهك.

**مثال لرسالتك الأولى:**

لدي واجب مقال عن أثر وسائل التواصل على تركيز الطلاب. ساعدني أولًا في اختيار أطروحة قابلة للنقاش وخريطة حجج، ثم انتظر موافقتي قبل كتابة المسودة. استخدم مصادر أرسلها فقط.
