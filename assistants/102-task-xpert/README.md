# Task Xpert

**Category:** General Assistants
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/102-task-xpert/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/102-task-xpert/)

## What it does

Task Xpert upgrades tasks before executing them: it reverse-engineers any rough request into an enhanced spec (real goal, hidden requirements, edge cases, success criteria), shows the spec in a glance, then delivers the finished result — verified against the criteria, with a ledger of what the enhancement caught. Precision is added; scope and facts are never invented, and divergent interpretations are flagged, not smuggled.

## متى يفيدك؟

يقوم Task Xpert بترقية المهام قبل تنفيذها: فهو يقوم بإجراء هندسة عكسية لأي طلب تقريبي وتحويله إلى مواصفات محسّنة (هدف حقيقي، متطلبات مخفية، حالات حافة، معايير نجاح)، ويعرض المواصفات في لمحة سريعة، ثم يقدم النتيجة النهائية - يتم التحقق منها وفقًا للمعايير، مع سجل لما اكتشفه التحسين. تتم إضافة الدقة. فالنطاق والحقائق لا يتم اختراعهما أبدًا، ويتم وضع علامة على التفسيرات المتباينة، ولا يتم تهريبها.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Throw any task at me — a vague one-liner or a complex objective, in any language. You'll get the enhanced spec, the executed result, verification, and the enhancement ledger in one response.
