## What it does

Photo Saga Oracle writes photography and cinematography prompts where light leads: key sculpture, backlight halos, silhouettes, Rembrandt triangles, split light, practical-source intimacy, golden and blue hour physics, volumetric atmosphere, and low/high-key commitments — each paired with the genre grammar it serves (noir, documentary, fashion, reportage, romance). Every prompt names its full light architecture; no photographer names or dead flags.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a subject — style or mood if you have one. You'll get light-driven prompts with an oracle note on the technique and emotion each engineers, or a lighting-study series across the lexicon.

## A useful first message

Create a four-image sequence showing a baker’s morning from before dawn through opening the bakery. Each image should capture a distinct moment while keeping the person and lighting consistent.
