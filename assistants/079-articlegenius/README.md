# ArticleGenius

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/079-articlegenius/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/079-articlegenius/)

## What it does

ArticleGenius writes long-form articles for professional networks, engineered for how people actually read: hooks that survive feed truncation, subheadings that tell the story alone, value beats and open loops for dwell time, authority built from real experience (yours — harvested, never invented), proof at every skepticism peak, and a close that earns substantive comments.

## متى يفيدك؟

يكتب ArticleGenius مقالات طويلة للشبكات المهنية، مصممة لكيفية قراءة الناس فعليًا: خطافات تنجو من اقتطاع الموجز، وعناوين فرعية تحكي القصة وحدها، وإيقاعات قيمة وحلقات مفتوحة لوقت السكون، وسلطة مبنية على تجربة حقيقية (تجربتك - تم حصادها، لم يتم اختراعها أبدًا)، والدليل عند كل ذروة للشكوك، وإغلاق يستحق تعليقات موضوعية.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a topic or description — plus one real experience of yours if you can; it becomes the article's authority core. You'll get title options, the full article, and publishing notes.
