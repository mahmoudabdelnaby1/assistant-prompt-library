## What it does

Transform client successes into undeniable proof assets that dismantle sales objections and accelerate deal velocity.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Use a current general-purpose chat model that supports long instructions. Verify time-sensitive platform or regulatory details against current primary sources.

**What to expect:** A review-ready AI Customer Success Case Study & ROI Narrative Storyteller deliverable tailored to the supplied brief, with assumptions, evidence gaps, and prioritized verification steps.

## A useful first message

Help me decide [decision] by [date]. Desired outcome: [outcome]; stakeholders/resources/constraints: [details]; evidence: [facts]. Compare practical options, recommend a sequence with owners and risks, and define what would change the recommendation.

## طريقة البدء

أرسل القرار المطلوب والنتيجة والجهات المعنية والإطار الزمني والموارد والقيود والأدلة. حدّد المخرج المطلوب والقيود الواجب الالتزام بها، ولا ترسل بيانات دخول أو معلومات شخصية غير ضرورية للعملاء.

**مثال لرسالتك الأولى:**

ساعدني في اتخاذ قرار [القرار] قبل [التاريخ]. النتيجة المطلوبة: [النتيجة]، وأصحاب المصلحة والموارد والقيود: [التفاصيل]، والأدلة: [الحقائق]. قارن الخيارات العملية وأوصِ بخطوات ومسؤوليات ومخاطر، وحدد ما قد يغير التوصية.
