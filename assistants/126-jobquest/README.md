## What it does

JobQuest runs realistic mock interviews: the bot embodies a hiring manager calibrated to your target role, asking one question at a time with evidence-seeking follow-ups, role-specific probes, and curveballs at your chosen difficulty (graduate-friendly to executive-pressure, opt-in stress mode). Optional coach breaks deliver exact stronger phrasings; the final debrief gives the honest hire-frame, your top fixes, and the practice prescription. Interviews run in the language of the real room.

## متى يفيدك؟

تجري JobQuest مقابلات وهمية واقعية: يجسد الروبوت مدير توظيف يتم معايرته وفقًا لدورك المستهدف، ويطرح سؤالًا واحدًا في كل مرة مع متابعات للبحث عن الأدلة، وتحقيقات خاصة بالأدوار، ومنحنيات في الصعوبة التي اخترتها (صديق للخريجين للضغط التنفيذي، واختيار وضع الضغط). توفر فترات الراحة الاختيارية للمدرب عبارات أقوى تمامًا؛ يقدم الاستجواب النهائي إطار التوظيف الصادق، وأهم الإصلاحات، ووصفة التدريب. تجري المقابلات بلغة الغرفة الحقيقية.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Name your target role — level and market help — and pick a difficulty, or just say "start". The interview begins in the same reply: calibration line, then question one.

## A useful first message

I am preparing for a mid-level paid media manager interview. Run a practice interview: ask one question at a time, wait for my answer before continuing, then give practical feedback.

## طريقة البدء

قم بتسمية دورك المستهدف — المستوى ومساعدة السوق — واختر الصعوبة، أو فقط قل "ابدأ". تبدأ المقابلة بنفس الرد: سطر المعايرة، ثم السؤال الأول.

**مثال لرسالتك الأولى:**

أستعد لمقابلة لوظيفة مدير حملات إعلانية بمستوى متوسط. أجرِ معي مقابلة تدريبية: اسألني سؤالًا واحدًا كل مرة، وانتظر إجابتي قبل السؤال التالي، ثم أعطني ملاحظات عملية.
