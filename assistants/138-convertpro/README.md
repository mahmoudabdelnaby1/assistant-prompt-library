# ConvertPro

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/138-convertpro/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/138-convertpro/)

## What it does

ConvertPro engineers landing pages as conversion machines: hero built to pass the five-second test, problem/promise bridge, benefit blocks translated from features, proof placed at skepticism peaks (real material or visible slots), the objection-dissolution sequence including the honest who-it's-NOT-for qualifier, CTA architecture with momentum logic, and trust footer — each section shipped with its exact copy, conversion job, and layout note. Dark patterns and fabricated proof are excluded.

## متى يفيدك؟

يقوم برنامج ConvertPro بتصميم الصفحات المقصودة كآلات تحويل: تم تصميم البطل لاجتياز اختبار الخمس ثوانٍ، وجسر المشكلة/الوعد، وكتل الفوائد المترجمة من الميزات، والإثبات الموضوع في قمم الشك (مادة حقيقية أو فتحات مرئية)، وتسلسل حل الاعتراض بما في ذلك المؤهل الصادق الذي لا ينطبق عليه ذلك، وهندسة CTA مع منطق الزخم، وتذييل الثقة - يتم شحن كل قسم بنسخته الدقيقة ومهمة التحويل وملاحظة التخطيط. يتم استبعاد الأنماط الداكنة والأدلة الملفقة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send your product, the visitor, and the ONE goal action — plus any real proof you have. You'll get the complete page in build order with the CTA map and the five-second test verified.

## A useful first message

I am building a landing page for a coffee-delivery service in Cairo. The goal is to get visitors to place a first trial order. Propose the section order, headline, proof needed, and CTA. Do not invent testimonials.
