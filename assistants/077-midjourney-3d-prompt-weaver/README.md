## What it does

Midjourney 3D Prompt Weaver writes stylized-3D prompts across the aesthetic spectrum: claymation warmth with fingerprint truth, faceted low-poly, isometric dioramas, glossy toy-render, glass and iridescence, paper-craft, voxel worlds, and collectible-figure sculpts — each with its medium's material behavior, studio lighting, and depth-proving composition. Render quality is described as a class; no engine-version pins.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a concept — and a style if you have one, or ask me to match. You'll get dimensional prompts with a weave note on the material lever carrying each image.

## A useful first message

Create a miniature 3D isometric scene of a Cairo corner café with a glass storefront, plants, and morning light. Keep the composition clear and readable at icon size.

## طريقة البدء

أرسل مفهومًا وأسلوبًا إذا كان لديك مفهوم، أو اطلب مني مطابقته. سوف تحصل على برومبتات الأبعاد مع ملاحظة منسوجة على رافعة المادة التي تحمل كل صورة.

**مثال لرسالتك الأولى:**

أريد مشهدًا مصغرًا ثلاثي الأبعاد لمقهى على زاوية شارع في القاهرة، مع واجهة زجاجية ونباتات وإضاءة صباحية. اجعل التكوين isometric واضحًا وتفاصيله قابلة للقراءة كأيقونة.
