# Customer Avatar Builder

**Category:** Writing & Storytelling  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/033-customer-avatar-builder/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/033-customer-avatar-builder/)

## What it does

Customer Avatar Builder creates detailed buyer avatars: identity and mindset quote, demographics, professional profile, goals and values, fears, three-layer jobs-to-be-done, purchase journey with real objections, media diet by channel type, a day-in-the-life narrative, and a message-resonance map with ready ad angles — plus an insight-to-action table. Named examples are flagged for verification; statistics are never fabricated.

## متى يفيدك؟

يقوم Customer Avatar Builder بإنشاء صور رمزية تفصيلية للمشتري: اقتباس الهوية والعقلية، والتركيبة السكانية، والملف الشخصي المهني، والأهداف والقيم، والمخاوف، والمهام ثلاثية الطبقات التي يتعين إنجازها، ورحلة الشراء مع الاعتراضات الحقيقية، ونظام الوسائط حسب نوع القناة، وسرد يوم في الحياة، وخريطة صدى الرسالة مع زوايا إعلانية جاهزة - بالإضافة إلى جدول رؤى للتنفيذ. يتم وضع علامة على الأمثلة المذكورة للتحقق منها؛ الإحصائيات ليست ملفقة أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your product and market. You'll get a complete avatar build sheet — psychology, journey, objections, media diet, and message angles — with an action table translating each insight into a marketing decision.

## A useful first message

I sell a monthly coffee subscription. Here is what I know about current customers: [data]. Build likely segments, motivations, and objections, and distinguish evidence from questions needing research.

## طريقة البدء

قم بوصف منتجك وسوقك. ستحصل على ورقة تصميم كاملة للصورة الرمزية - علم النفس، والرحلة، والاعتراضات، والنظام الغذائي للوسائط، وزوايا الرسائل - مع جدول إجراءات يترجم كل فكرة إلى قرار تسويقي.

**مثال لرسالتك الأولى:**

أبيع اشتراك قهوة شهرية. هذه معلوماتي عن العملاء الحاليين: [البيانات]. كوّن شرائح محتملة ودوافعها واعتراضاتها، وميّز ما تدعمه البيانات عما يحتاج إلى بحث.
