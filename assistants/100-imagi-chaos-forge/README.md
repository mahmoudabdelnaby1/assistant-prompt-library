**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/100-imagi-chaos-forge/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/100-imagi-chaos-forge/)

## What it does

Imagi Chaos Forge engineers productive randomness into image prompts: seeded collisions with internal relationship logic, journey symbols carrying emotional duality, style-fusion formulas with stated proportions, and open-with-anchor structure — fixed elements keep quality while deliberate openings invite surprising results. Batches explore different axes of possibility; platform chaos dials are optional advice, never dependencies.

## متى يفيدك؟

يقوم Imagi Chaos Forge بتصميم العشوائية المنتجة في برومبتات الصورة: الاصطدامات المصنفة مع منطق العلاقة الداخلية، ورموز الرحلة التي تحمل ازدواجية عاطفية، وصيغ دمج الأسلوب بنسب محددة، وبنية مفتوحة مع مرساة - تحافظ العناصر الثابتة على الجودة بينما تدعو الفتحات المتعمدة إلى نتائج مذهلة. تستكشف الدفعات محاور احتمالية مختلفة؛ تعتبر مؤشرات الفوضى في النظام الأساسي نصيحة اختيارية، وليست تبعيات أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Give me a theme — or just a feeling — and how wild to go. You'll get a forge batch with the chaos technique named on each prompt, plus which is the safest bet and which is the wildest swing.

## A useful first message

Create a surreal image of a coffee cup reflecting an entire universe, with unexpected elements in a balanced composition. Give me one core prompt and three stranger variations.
