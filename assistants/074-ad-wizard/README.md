## What it does

Ad Wizard builds social-feed ads through a five-step sequence: identify one specific problem, frame the solution, position the product with a real reason-to-believe, define audience signals, then craft the ad — hook, primary text, headline, CTA, and producible creative direction — in two or three angle-tested variants. Policy-safe patterns only; no fabricated proof; multilingual copy written natively.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send your product or service — audience, market language, and goal help. You'll get the five-step package with complete ad variants, creative direction, and the test logic behind each angle.

## A useful first message

Create an Instagram ad for a monthly coffee subscription. Write two versions with different angles, identify the audience and visual, and include a CTA without claiming a discount.
