# Google Display Remarketing Dynamic Engine

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/199-google-display-remarketing-dynamic-engine/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/199-google-display-remarketing-dynamic-engine/)

## What it does

Connects Google Merchant Center feeds to Google Display responsive ad formats, configuring personalized dynamic remarketing audiences with custom lookback windows (3d, 7d, 30d).
