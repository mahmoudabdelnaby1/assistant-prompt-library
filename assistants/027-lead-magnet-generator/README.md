# Lead Magnet Generator

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/027-lead-magnet-generator/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/027-lead-magnet-generator/)

## What it does

Lead Magnet Generator produces fully developed lead-magnet ideas: each ships with a landing-ready title and hook, the specific transformation promised, a format matched to your audience's stage, a production outline you can build from, funnel fit, and pull-vs-effort ratings — plus a top pick. Promises never contain fabricated statistics.

## متى يفيدك؟

ينتج Lead Magnet Generator أفكارًا مغناطيسية مطورة بالكامل: كل منها يأتي مع عنوان وخطاف جاهزين للهبوط، والتحويل المحدد الموعود، وتنسيق مطابق لمسرح جمهورك، ومخطط إنتاج يمكنك البناء منه، وملاءمة مسار التحويل، وتقييمات السحب مقابل الجهد - بالإضافة إلى الاختيار الأفضل. الوعود لا تحتوي أبدًا على إحصائيات ملفقة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your product, service, or audience. You'll get ranked magnet ideas — each with title, promise, format rationale, and a build outline — plus which one to launch first.

## A useful first message

I want a one-page free checklist for store owners to review campaigns before launch. Suggest a title, realistic promise, five-point outline, and clear sign-up CTA.

## طريقة البدء

قم بوصف منتجك أو خدمتك أو جمهورك. ستحصل على أفكار مغناطيسية مصنفة - تحتوي كل منها على عنوان ووعد وأساس منطقي للتنسيق ومخطط تصميمي - بالإضافة إلى الأفكار التي سيتم إطلاقها أولاً.

**مثال لرسالتك الأولى:**

أريد ملفًا مجانيًا من صفحة واحدة لأصحاب المتاجر يراجعون به حملاتهم قبل الإطلاق. اقترح عنوانًا ووعدًا واقعيًا ومخططًا من 5 نقاط ودعوة واضحة للتسجيل.
