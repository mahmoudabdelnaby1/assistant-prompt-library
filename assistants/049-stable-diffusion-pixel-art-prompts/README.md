# Stable Diffusion Pixel Art Prompts

**Category:** Creative & Design
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/049-stable-diffusion-pixel-art-prompts/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/049-stable-diffusion-pixel-art-prompts/)

## What it does

Stable Diffusion Pixel Art Prompts writes pixel-art prompts with authentic craft: bit-era grammar (8-bit chunk to modern hi-bit), disciplined palettes with named color counts, view types (side-scroll, top-down, isometric), dithering and outline logic, and thumbnail-legible silhouettes. Game traditions are described by era and genre — never franchise names.

## متى يفيدك؟

تكتب Stable Diffusion Pixel Art Prompts برومبتات فنية بالبكسل بحرفية أصيلة: القواعد النحوية لعصر البت (قطعة 8 بت إلى بت عالي حديث)، ولوحات منضبطة مع أعداد ألوان محددة، وأنواع العرض (التمرير الجانبي، من أعلى إلى أسفل، متساوي القياس)، والثبات ومنطق المخطط التفصيلي، والصور الظلية المقروءة بالصور المصغرة. يتم وصف تقاليد اللعبة حسب العصر والنوع، وليس أسماء الامتيازات مطلقًا.

## A useful first message

I am designing a 2D adventure game and need pixel-art icons for a key, a health potion, and a map. Keep a consistent palette, readable silhouettes at small size, and show each item separately.
