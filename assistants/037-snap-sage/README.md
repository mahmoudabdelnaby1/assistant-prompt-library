# Snap Sage

**Category:** Marketing & SEO  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/037-snap-sage/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/037-snap-sage/)

## What it does

Snap Sage delivers image prompts as a photographer's spec sheet: subject, five precision keywords, camera class, lens character, time of day, photography style, film aesthetic, realism level, lighting design, and aspect ratio — woven into one paste-ready prompt plus the field breakdown so you can change any dial. Gear is described as class and character, not brand incantations; flags stay optional.

## متى يفيدك؟

يقدم Snap Sage برومبتات بالصور كورقة مواصفات للمصور الفوتوغرافي: الموضوع، وخمس كلمات رئيسية دقيقة، وفئة الكاميرا، وشخصية العدسة، والوقت من اليوم، وأسلوب التصوير الفوتوغرافي، وجمالية الفيلم، ومستوى الواقعية، وتصميم الإضاءة، ونسبة العرض إلى الارتفاع - منسوجة في موجه واحد جاهز للنسخ واللصق بالإضافة إلى تفصيل المجال حتى تتمكن من تغيير أي قرص. يتم وصف العتاد على أنه الطبقة والشخصية، وليس تعويذات العلامة التجارية؛ تبقى الأعلام اختيارية.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Name a subject — that's enough. You'll get spec-sheet prompts with the ten fields broken down, so you can re-light, re-lens, or re-style any shot by naming the dial.

## A useful first message

The keyword is “renewal.” Create a table of image prompts using this idea in distinct visual styles, keeping each prompt concise and visually specific.

## طريقة البدء

قم بتسمية موضوع ما - وهذا يكفي. ستحصل على برومبتات بورقة المواصفات مع تقسيم الحقول العشرة، حتى تتمكن من إعادة إضاءة أي لقطة أو إعادة عدساتها أو إعادة تصميمها عن طريق تسمية القرص.

الكلمة المفتاحية هي «التجدد». أنشئ جدولًا من أوصاف الصور بهذه الكلمة بأساليب فنية مختلفة، واجعل كل وصف قصيرًا ومميزًا بصريًا.
