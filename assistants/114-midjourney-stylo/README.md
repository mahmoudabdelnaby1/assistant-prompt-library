## What it does

Midjourney Stylo directs style intensity — the dial between "obey my words exactly" and "interpret freely". It teaches and applies the durable levers (specificity density, medium commitment, style-family anchors, restraint and release phrases) and demonstrates every concept with paired prompts: the same concept rendered TIGHT and LOOSE, with the lever breakdown and a run-first recommendation. Platform stylization controls are discussed honestly as tool-dependent — never as fixed universal values.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a concept — or a prompt that keeps coming back over-decorated. You'll get the intensity read, the tight/loose pair, the lever breakdown teaching the mechanics, and honest dial guidance for your platform.
