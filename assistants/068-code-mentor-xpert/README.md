## What it does

Code Mentor Xpert reviews and teaches code across languages: severity-ranked findings (correctness, security, performance, readability) each tied to its principle, a complete justified refactor, transferable principles with fresh examples, honest complexity analysis, and a growth exercise targeting your weakest muscle. Code here is generated and traced line by line, not executed — unverified behavior is marked, never claimed as tested.

## متى يفيدك؟

يقوم Code Mentor Xpert بمراجعة التعليمات البرمجية وتعليمها عبر اللغات: النتائج المصنفة حسب درجة الخطورة (الصحة، الأمان، الأداء، سهولة القراءة) كل منها مرتبط بمبدأه، وإعادة بناء مبررة كاملة، ومبادئ قابلة للتحويل مع أمثلة جديدة، وتحليل التعقيد الصادق، وتمرين النمو الذي يستهدف أضعف عضلاتك. يتم إنشاء التعليمات البرمجية هنا وتتبعها سطرًا تلو الآخر، ولا يتم تنفيذها - يتم وضع علامة على السلوك الذي لم يتم التحقق منه، ولا يتم المطالبة به مطلقًا على أنه تم اختباره.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A capable coding chat model. Include the relevant code or error message when needed.

**What to expect:** Paste code, an error, or a concept question — any language. You'll get findings with reasons, the full refactor with a change log, the principles at play, and one practice exercise. Level calibration is automatic.

## A useful first message

My HTML contact form fails when submitted. Here is the code and error: [paste them]. Explain the cause step by step, suggest the smallest safe fix, and show how to verify it.

## طريقة البدء

الصق رمزًا أو خطأ أو سؤالاً مفاهيميًا - بأي لغة. سوف تحصل على النتائج مع الأسباب، وإعادة البناء الكاملة مع سجل التغيير، والمبادئ المطبقة، وتمرين تدريبي واحد. معايرة المستوى تلقائية.

**مثال لرسالتك الأولى:**

لدي خطأ في نموذج تواصل HTML عند إرسال البيانات. هذا الكود ورسالة الخطأ: [الصقها]. اشرح السبب خطوة خطوة، واقترح أصغر تعديل آمن ثم طريقة التحقق.
