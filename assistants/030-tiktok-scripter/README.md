# TikTok Scripter

**Category:** Marketing & SEO  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/030-tiktok-scripter/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/030-tiktok-scripter/)

## What it does

TikTok Scripter writes complete short-video scripts: a dual hook (verbal + visual) in the first seconds, beat-by-beat structure with exact spoken lines and on-screen text, phone-filmable shot directions, caption and hashtags, sound direction by mood and tempo, and filming notes. Scripts are written natively in your audience's language; trend references stay durable, never dead specifics.

## متى يفيدك؟

يكتب TikTok Scripter نصوصًا كاملة لمقاطع الفيديو القصيرة: خطاف مزدوج (لفظي + مرئي) في الثواني الأولى، وبنية إيقاعية مع خطوط منطوقة دقيقة ونص على الشاشة، واتجاهات اللقطات القابلة للتصوير عبر الهاتف، والتسمية التوضيحية وعلامات التصنيف، وتوجيه الصوت حسب الحالة المزاجية والإيقاع، وملاحظات التصوير. تتم كتابة النصوص باللغة الأصلية لجمهورك؛ تبقى مراجع الاتجاه متينة، ولا تموت أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Give me a theme — plus goal, audience language, and length if you know them. You'll get a shoot-ready script package: hooks with alternates, timed beats, caption, hashtags, and production notes.

## A useful first message

Write a 30-second vertical video script for a new Cairo café: a strong opening hook, three short shots, simple voice-over, and an invitation to visit. Use natural Egyptian Arabic and do not add an unverified offer or price.

## طريقة البدء

أعطني موضوعًا - بالإضافة إلى الهدف ولغة الجمهور والطول إذا كنت تعرفهم. ستحصل على حزمة نصية جاهزة للتصوير: خطافات مع البدائل، والإيقاعات الموقوتة، والتسمية التوضيحية، وعلامات التصنيف، وملاحظات الإنتاج.

**مثال لرسالتك الأولى:**

اكتب سيناريو فيديو عمودي مدته 30 ثانية لمقهى جديد في القاهرة: افتتاحية تشد الانتباه، 3 لقطات قصيرة، تعليق صوتي بسيط، ودعوة لزيارة المكان. اجعل اللغة مصرية طبيعية ولا تضف عرضًا أو سعرًا غير مؤكد.
