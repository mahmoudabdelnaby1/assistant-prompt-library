# Avatar Craft

**Category:** General Assistants  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/097-avatar-craft/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/097-avatar-craft/)

## What it does

Avatar Craft directs digital-avatar prompts for the small frame: icon-size readability, circular-crop safety, committed aesthetics (cyberpunk neon, fantasy elegance, professional warmth, anime vibrancy, pixel retro, stylized 3D, minimal line), identity signature marks, face-sculpting light with catchlights, and separating backgrounds. Identity sets keep one persona consistent across every style via a locked anchor.

## متى يفيدك؟

تقوم Avatar Craft بتوجيه برومبتات الصورة الرمزية الرقمية للإطار الصغير: سهولة قراءة حجم الأيقونة، وسلامة المحاصيل الدائرية، والجماليات الملتزمة (نيون Cyberpunk، والأناقة الخيالية، والدفء الاحترافي، وحيوية الرسوم المتحركة، والبكسل القديم، والثلاثية الأبعاد المنمقة، والخط البسيط)، وعلامات توقيع الهوية، وضوء نحت الوجه مع أضواء كاشفة، وخلفيات منفصلة. تحافظ مجموعات الهوية على شخصية واحدة متسقة عبر كل نمط من خلال مرساة مقفلة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Tell me who the avatar represents — plus an aesthetic and where it'll be used. You'll get small-frame-engineered prompts with an art-director note, or a cross-style identity set on one locked anchor.

## A useful first message

Create a visual concept for a virtual travel guide in Egypt: a welcoming look, small bag, and practical clothing. Write a cohesive prompt suitable for a profile image.

## طريقة البدء

أخبرني من تمثله الصورة الرمزية - بالإضافة إلى الشكل الجمالي وأين سيتم استخدامه. ستحصل على برومبتات مصممة بإطار صغير مع ملاحظة مدير فني، أو هوية ذات نمط متقاطع تم تعيينها على مرساة واحدة مقفلة.

**مثال لرسالتك الأولى:**

صمّم فكرة شخصية افتراضية لمرشدة سفر في مصر: مظهر ودود، حقيبة صغيرة، وملابس عملية. اكتب وصفًا بصريًا متماسكًا يصلح لصورة ملف شخصية.
