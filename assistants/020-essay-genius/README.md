# Essay Genius

**Category:** Writing & Storytelling
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/020-essay-genius/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/020-essay-genius/)

## What it does

Essay Genius works in three modes on argumentative and academic essays: COACH (step-by-step guidance with worked examples), DRAFT (a complete original essay with margin notes explaining the craft), and REVIEW (rubric critique of your draft with line-level fixes). It forges debatable theses, steelmans counterarguments, and never fabricates sources — unverifiable references become honest placeholders.

## متى يفيدك؟

يعمل Essay Genius في ثلاثة أوضاع للمقالات الجدلية والأكاديمية: COACH (إرشادات خطوة بخطوة مع أمثلة عملية)، DRAFT (مقال أصلي كامل مع ملاحظات هامشية تشرح الحرفة)، وREVIEW (نقد معياري لمسودتك مع إصلاحات على مستوى السطر). إنه يصوغ أطروحات قابلة للنقاش، وحجج ستيلمان المضادة، ولا يختلق المصادر أبدًا - تصبح المراجع التي لا يمكن التحقق منها عناصر نائبة صادقة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Give me a topic and pick a mode — coach, draft, or review (paste your draft for review). Length and citation style help if you have them; otherwise I'll propose sensible defaults.

## A useful first message

I have an essay assignment on how social media affects students’ attention. First help me choose a debatable thesis and argument map, then wait for my approval before drafting. Use only sources I provide.

## طريقة البدء

أعطني موضوعًا واختر الوضع - مدرب، أو مسودة، أو مراجعة (الصق مسودتك للمراجعة). يساعد الطول وأسلوب الاقتباس إذا كان لديك؛ وإلا سأقترح افتراضات معقولة.

**مثال لرسالتك الأولى:**

لدي واجب مقال عن أثر وسائل التواصل على تركيز الطلاب. ساعدني أولًا في اختيار أطروحة قابلة للنقاش وخريطة حجج، ثم انتظر موافقتي قبل كتابة المسودة. استخدم مصادر أرسلها فقط.
