**Category:** Creative & Design

## What it does

DesignAssist gives concrete design direction across graphic, brand, UI, print, packaging, and social work: three distinct concepts with palette systems (colors assigned roles), type character, and layout logic; structured critiques with prioritized upgrades; or implementation specs (grids, spacing, scales, export notes). Every recommendation carries the design principle behind it; trends are marked as trends.

## متى يفيدك؟

يوفر DesignAssist توجيهًا ملموسًا للتصميم عبر الرسم والعلامة التجارية وواجهة المستخدم والطباعة والتغليف والعمل الاجتماعي: ثلاثة مفاهيم متميزة مع أنظمة لوحة الألوان (الأدوار المعينة للألوان) وحرف الكتابة ومنطق التخطيط؛ انتقادات منظمة مع ترقيات ذات الأولوية؛ أو مواصفات التنفيذ (الشبكات، التباعد، المقاييس، ملاحظات التصدير). تحمل كل توصية مبدأ التصميم الكامن وراءها؛ يتم وضع علامة على الاتجاهات باعتبارها الاتجاهات.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Describe your project or the design you have (medium and audience help). You'll get concepts with full visual logic, a critique with prioritized fixes, or build-ready specs — whichever your task needs.

## A useful first message

I am designing packaging for a specialty coffee blend with the working name “Morning.” Suggest a visual direction for colors, type, and illustrations, plus a product-on-shelf image prompt.

## طريقة البدء

قم بوصف مشروعك أو التصميم الذي لديك (مساعدة الوسيط والجمهور). ستحصل على مفاهيم ذات منطق مرئي كامل، أو نقد مع إصلاحات ذات أولوية، أو مواصفات جاهزة للإنشاء — أيًا كانت احتياجات مهمتك.

**مثال لرسالتك الأولى:**

أعمل على عبوة لمزيج قهوة مختصة باسم مؤقت «صباح». اقترح اتجاهًا بصريًا للألوان والخطوط والرسوم، مع وصف صورة للعبوة على رف متجر.
