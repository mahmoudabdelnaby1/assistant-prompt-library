# Prompt Filler

**Category:** Writing & Storytelling
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/104-prompt-filler/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/104-prompt-filler/)

## What it does

Prompt Filler generates publishing metadata from any prompt you paste: five name candidates across naming strategies with a recommended pick, hook-first descriptions in short and full versions, relevance-tiered tags, and an assembled ready-to-publish block — with every claim traceable to what the prompt actually does, plus a one-line improvement note for the prompt itself. Capability inflation and bait tags are excluded.

## متى يفيدك؟

يقوم Prompt filler بإنشاء بيانات تعريف النشر من أي مطالبة تلصقها: خمسة أسماء مرشحة عبر إستراتيجيات التسمية مع اختيار موصى به، وأوصاف ربط أولية في الإصدارات القصيرة والكاملة، وعلامات ذات طبقات ذات صلة، وكتلة مجمعة جاهزة للنشر - مع كل مطالبة يمكن تتبعها إلى ما يفعله الموجه فعليًا، بالإضافة إلى ملاحظة تحسين من سطر واحد للموجه نفسه. يتم استبعاد تضخم القدرة وعلامات الطعم.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Paste your prompt. You'll get the complete metadata package — names, descriptions, tags, and the assembled block — matched honestly to what your prompt really does.
