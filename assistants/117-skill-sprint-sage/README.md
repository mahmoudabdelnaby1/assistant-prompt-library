## What it does

Skill Sprint Sage designs hands-on practice systems for any skill — zero courses required: the sub-skill map with 80/20 priorities, a daily routine in real time blocks (the 15-minute drill fully specified, commute reps, weekend deep session), real-world practice arenas enterable this week, objective checkpoints, and a plateau kit. Every drill carries its feedback mechanism; schedules respect your actual available time. Resources are named by type and durable classics — links are never invented.

## متى يفيدك؟

تصمم Skill Sprint Sage أنظمة تدريب عملية لأي مهارة - لا توجد دورات مطلوبة: خريطة المهارات الفرعية ذات أولويات 80/20، وروتين يومي في مجموعات في الوقت الفعلي (تمرين مدته 15 دقيقة محدد بالكامل، وممثلي التنقل، وجلسة عميقة في عطلة نهاية الأسبوع)، وساحات تدريب واقعية يمكن الدخول إليها هذا الأسبوع، ونقاط تفتيش موضوعية، ومجموعة أدوات ثابتة. يحمل كل تدريب آلية التغذية الراجعة الخاصة به؛ تحترم الجداول الزمنية الوقت الفعلي المتاح لديك. يتم تسمية الموارد حسب النوع والكلاسيكيات الدائمة - لا يتم اختراع الروابط أبدًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Name a skill plus your real available time (current level helps). You'll get the complete sprint plan — routine, arenas, checkpoints, plateau kit — sized to survive your actual weeks.

## A useful first message

I want to learn Google Analytics 4 basics in two weeks and have 30 minutes each day. Create a short daily plan with a practical exercise and a way to check my understanding.

## طريقة البدء

قم بتسمية مهارة بالإضافة إلى الوقت الحقيقي المتاح لديك (المستوى الحالي يساعد). ستحصل على خطة العدو الكاملة - الروتينية، والساحات، ونقاط التفتيش، ومجموعة أدوات الهضبة - بحجم يناسب أسابيعك الفعلية.

**مثال لرسالتك الأولى:**

أريد تعلم أساسيات Google Analytics 4 خلال أسبوعين، ولدي 30 دقيقة يوميًا. أنشئ خطة يومية قصيرة تتضمن تمرينًا عمليًا وطريقة أتأكد بها أنني فهمت كل خطوة.
