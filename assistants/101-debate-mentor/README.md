# Debate Mentor

**Category:** General Assistants
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/101-debate-mentor/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/101-debate-mentor/)

## What it does

Debate Mentor trains argumentation, persuasion, and negotiation actively: techniques taught in three layers (principle → exact phrases and moves → drill), live sparring against calibrated opponents from friendly colleague to hostile adversary, pause-and-coach freezes, evidence-based debrief scorecards, and argument builds with steelmanned opposition. Persuasion ethics are enforced — manipulation patterns are taught for defense only.

## متى يفيدك؟

يقوم مرشد المناظرة بتدريب الجدال والإقناع والتفاوض بشكل نشط: التقنيات التي يتم تدريسها في ثلاث طبقات (المبدأ ← العبارات والحركات الدقيقة ← التدريب)، والسجال المباشر ضد خصوم محددين من زميل ودود إلى خصم معاد، والتوقف المؤقت والمدرب، وبطاقات أداء استخلاص المعلومات المبنية على الأدلة، وبناء الجدال مع المعارضة القوية. يتم فرض أخلاقيات الإقناع، ويتم تدريس أنماط التلاعب للدفاع فقط.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Pick a mode: spar on a motion (choose your side and opponent level), architect a real argument you'll defend, train a composure weakness, or learn a technique. Training starts in the same reply.

## A useful first message

I am deciding between leasing a café space and starting with delivery only. Compare the options by cost, risk, and speed to test, then ask me for missing information before recommending one.

## طريقة البدء

اختر وضعًا: تنافس على الحركة (اختر جانبك ومستوى خصمك)، أو صمم حجة حقيقية ستدافع عنها، أو تدرب على ضعف رباطة جأشك، أو تعلم أسلوبًا. يبدأ التدريب في نفس الرد.

**مثال لرسالتك الأولى:**

أفكر في الاختيار بين استئجار موقع لمقهى أو البدء بالتوصيل فقط. قارن البديلين وفق التكلفة والمخاطر وسرعة الاختبار، ثم اسألني عن المعلومات الناقصة قبل التوصية.
