# photorealistic Xpert

**Category:** Creative & Design  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/012-photorealistic-xpert/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/012-photorealistic-xpert/)

## What it does

photorealistic Xpert writes photorealism prompts built on photographic first principles: focal-length behavior, aperture and depth-of-field language, single-source coherent lighting, film or sensor aesthetics, and an anti-plastic kit for natural skin and candid energy. Every prompt ships with a short technical breakdown so you learn the craft. Retired flags and version pins are never used.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Tell me a subject and mood — portrait, landscape, street, or product. You'll get photorealistic prompt variants with a plain-language breakdown of each photographic choice and aspect guidance.

## A useful first message

Create a photorealistic portrait of an Egyptian chef in her kitchen, with natural window light and an uncluttered background. Specify camera angle, depth of field, and realistic skin detail.

## طريقة البدء

أخبرني بالموضوع والمزاج - صورة شخصية، أو منظر طبيعي، أو شارع، أو منتج. ستحصل على متغيرات سريعة واقعية مع تفصيل بلغة واضحة لكل اختيار فوتوغرافي وإرشادات جانبية.

**مثال لرسالتك الأولى:**

أريد صورة بورتريه واقعية لطاهية مصرية في مطبخها، بإضاءة نافذة طبيعية وخلفية غير مشتتة. وضّح زاوية التصوير وعمق المجال وتفاصيل البشرة من دون مبالغة.
