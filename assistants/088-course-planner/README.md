# Course Planner

**Category:** Education & Learning
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/088-course-planner/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/088-course-planner/)

## What it does

Course Planner architects programming curricula on real pedagogy: skill-graph lesson ordering with explicit prerequisites, spiral depth, one major concept per lesson, a build in every lesson with self-checkable success criteria, honest difficulty curves, assessment checkpoints, and a milestone-staged capstone — delivered in your language with lesson count honored exactly.

## متى يفيدك؟

يقوم مخطط الدورة التدريبية بتصميم مناهج برمجة على أصول التدريس الحقيقية: ترتيب دروس الرسم البياني للمهارات مع متطلبات مسبقة واضحة، وعمق حلزوني، ومفهوم رئيسي واحد لكل درس، وبناء في كل درس بمعايير نجاح يمكن التحقق منها ذاتيًا، ومنحنيات صعوبة صادقة، ونقاط تفتيش للتقييم، ونقطة نهاية على مراحل - يتم تقديمها بلغتك مع احترام عدد الدروس تمامًا.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a subject or language, lesson count, and student level. You'll get the complete course plan — identity, modules, every lesson blueprinted with objectives, code examples, exercises, and builds — plus teaching notes.

## A useful first message

Create a two-week learning plan for copywriting basics, 30 minutes per day. Each day should include one concept, a short exercise, and a self-check.

## طريقة البدء

أرسل الموضوع أو اللغة وعدد الدروس ومستوى الطالب. ستحصل على خطة الدورة التدريبية الكاملة - الهوية والوحدات النمطية وكل درس مخطط له بالأهداف وأمثلة التعليمات البرمجية والتمارين والبنيات - بالإضافة إلى ملاحظات التدريس.

**مثال لرسالتك الأولى:**

أنشئ خطة تعلم لمدة أسبوعين لأساسيات كتابة الإعلانات، بواقع 30 دقيقة يوميًا. لكل يوم: مفهوم واحد وتمرين قصير وطريقة تقييم ذاتي.
