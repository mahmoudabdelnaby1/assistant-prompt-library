# VisionCraft Nexus

**Category:** Marketing & SEO  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/066-visioncraft-nexus/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/066-visioncraft-nexus/)

## What it does

VisionCraft Nexus turns one keyword into rich descriptive prompts for natural-language image generators: flowing prose built layer by layer — subject specificity, action, setting, light story, color psychology, committed medium, composition logic — delivered across a style spectrum (photorealistic to painterly to 3D) so you see the keyword's range. Tag piles and dead tokens are avoided by design.

## متى يفيدك؟

يقوم VisionCraft Nexus بتحويل كلمة رئيسية واحدة إلى برومبتات وصفية غنية لمولدات الصور باللغة الطبيعية: النثر المتدفق المبني طبقة تلو الأخرى - خصوصية الموضوع، والحركة، والإعداد، والقصة الخفيفة، وعلم نفس اللون، والوسيط الملتزم، ومنطق التركيب - يتم تسليمها عبر نطاق نمطي (من واقعي إلى تصويري إلى ثلاثي الأبعاد) حتى تتمكن من رؤية نطاق الكلمة الرئيسية. يتم تجنب أكوام العلامات والرموز الميتة حسب التصميم.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** A conversational text model, then an image generator that accepts text prompts.

**What to expect:** Send one keyword. You'll get a spectrum of prose prompts — each rendition re-imagined through a different medium's logic — with a note on which layer carries each image.

## A useful first message

I need three coordinated images for a herbal tea launch: the product, its preparation, and a moment of relaxation. Keep palette and visual identity consistent across all three.

## طريقة البدء

إرسال كلمة رئيسية واحدة. ستحصل على مجموعة من البرومبتات النثرية - يتم إعادة تصور كل عرض من خلال منطق وسيط مختلف - مع ملاحظة حول الطبقة التي تحمل كل صورة.

**مثال لرسالتك الأولى:**

أحتاج ثلاث صور متناسقة لحملة إطلاق شاي أعشاب: صورة للمنتج، وصورة لطريقة التحضير، وصورة للحظة الاسترخاء. حافظ على لوحة الألوان والهوية البصرية بين الصور.
