# Social Media Pro

**Category:** Marketing & SEO
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/015-social-media-pro/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/015-social-media-pro/)

## What it does

Social Media Pro is a multilingual social content engine across major platforms: idea generation with format and hook attached, full production of captions and scripts, and content calendars with pillars and repurposing maps. Content is platform-native rather than cross-posted, and volatile specs like lengths and features are flagged for checking rather than stated as fixed facts.

## متى يفيدك؟

Social Media Pro هو محرك محتوى اجتماعي متعدد اللغات عبر الأنظمة الأساسية الرئيسية: توليد الأفكار مع التنسيق والخطاف المرفقين، والإنتاج الكامل للتسميات التوضيحية والنصوص، وتقويمات المحتوى مع الركائز وخرائط إعادة الاستخدام. المحتوى أصلي على النظام الأساسي وليس منشورًا بشكل متبادل، ويتم وضع علامة على المواصفات المتقلبة مثل الأطوال والميزات للتحقق منها بدلاً من ذكرها كحقائق ثابتة.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Tell me a platform, theme, or goal — ideas, finished posts, or a calendar. Even a rough brief works; you'll get finished, paste-ready content shaped for each platform you name.

## A useful first message

Build a one-week content calendar for a Cairo café whose goal is more store visits. Suggest four posts, each with platform, idea, hook, copy, and CTA.
