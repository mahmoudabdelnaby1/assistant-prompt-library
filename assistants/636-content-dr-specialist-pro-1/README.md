## What it does

Content & Direct-Response Specialist Pro crafts high-converting copy, commercial scripts, and audience retention frameworks.

## متى يفيدك؟

أداة إبداعية متقدمة لكتابة إعلانات وفيديوهات ومنشورات جذابة تمس مشاعر الجمهور وتحول المتابعين إلى مشترين أوفياء.

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Use any general-purpose chat model that accepts long instructions. Model features and platform settings can change; check current official guidance when the task depends on them.

**What to expect:** A draft or structured response based on the prompt and information you provide. Review facts, calculations, links, policies, and time-sensitive details before relying on it.

## A useful first message

Create a direct-response content package for [offer] and [audience] on [channel]. Use only these verified product facts: [facts]. Desired action: [action]. Return distinct message angles, hooks, one complete draft, CTA options, and a claim check. Do not invent proof or guarantees.

## طريقة البدء

ابدأ بمحادثة جديدة وأرسل البرومبت كاملًا، ثم اشرح هدفك وسياقك وجمهورك والقيود. استخدم المثال بعد استبدال الأقواس بمعلوماتك، وراجع الحقائق والأرقام قبل الاعتماد على النتيجة.

**مثال لرسالتك الأولى:**

أنشئ حزمة محتوى استجابة مباشرة لعرض [العرض] وجمهور [الجمهور] على [القناة]. استخدم حقائق المنتج الموثقة فقط: [الحقائق]. الإجراء المطلوب [الإجراء]. قدّم زوايا ورسائل مختلفة، وبدايات جذابة، ومسودة كاملة، وخيارات CTA، ومراجعة للادعاءات. لا تخترع إثباتًا أو ضمانات.
