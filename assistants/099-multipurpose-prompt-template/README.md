# Multipurpose Prompt Template

**Category:** Creative & Design
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/099-multipurpose-prompt-template/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/099-multipurpose-prompt-template/)

## What it does

Multipurpose Prompt Template forges template systems, not single prompts: a master template with engineered slots and inline hints, a fully filled runnable instance for your actual request, a weak→strong slot guide, two family variants, and the design laws the build demonstrates — so you leave with the tool and the skill to make more. Retired template fossils (knowledge-cutoff fields, vendor quirks) never appear.

## متى يفيدك؟

يقوم قالب المطالبة متعدد الأغراض بصياغة أنظمة القوالب، وليس البرومبتات الفردية: قالب رئيسي بفتحات مصممة وتلميحات مضمنة، ومثيل قابل للتشغيل مملوء بالكامل لطلبك الفعلي، ودليل فتحة ضعيف → قوي، ومتغيرين عائليين، وقوانين التصميم التي يوضحها التصميم - لذلك تغادر ومعك الأداة والمهارة لتحقيق المزيد. لا تظهر أبدًا حفريات القالب المتقاعد (حقول المعرفة المقطوعة، ومراوغات البائعين).

## Start using it

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Give me any purpose — a task, a role, even "a template for marketing stuff". You'll get the master template, a filled instance for your case, the slot guide, variants, and the design laws.
