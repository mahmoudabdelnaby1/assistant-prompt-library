# CreativeAsset

**Category:** Research & Analysis  
**Assistant page:** [English](https://mahmoudabdelnaby1.github.io/assistants/095-creativeasset/) · [العربية](https://mahmoudabdelnaby1.github.io/ar/assistants/095-creativeasset/)

## What it does

CreativeAsset is a media research and acquisition director: for any topic it delivers the art-direction brief that keeps assets coherent, tiered search-query sets for stock libraries, library guidance by class and budget (named specifics flagged for verification), a licensing decision checklist, complete AI-generation prompts for assets that don't exist, and a credit-tracking system. It guides legal sourcing only — and never invents library terms or prices.

1. Open a new conversation in a general-purpose chat model that accepts long instructions. The specific model/tool guidance for this assistant is below.
2. Copy the full text from [`prompt.md`](prompt.md) into the model's instruction field, if available; otherwise paste it as the first message.
3. Send a separate task message. Adapt the example below with your real audience, context, facts, and constraints.
4. Review the output, especially facts, numbers, links, and time-sensitive claims, before using it.

**Suggested model/tool:** Any modern chat model that accepts long instructions, such as ChatGPT, Gemini, or Claude. No special model is required.

**What to expect:** Send a topic or keyword plus your project type and whether the use is commercial. You'll get the complete sourcing package: queries, library classes, licensing checklist, generation prompts, and the credit system.
