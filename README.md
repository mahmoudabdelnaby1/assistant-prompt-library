# Assistant Prompt Library

A growing, searchable collection of reusable AI assistant prompts across marketing, business, research, writing, creative work, education, and technology. Each entry explains the task it supports, how to start, what to expect, and what to review.

**1000 active entries, generated from the catalog** · [Browse the visual library](https://mahmoudabdelnaby1.github.io/#assistant-library) · [Portfolio](https://mahmoudabdelnaby1.github.io/) · [LinkedIn](https://eg.linkedin.com/in/mahmoudabdelnaby4)

> These are prompt files, not hosted or executable bots. They run inside a separate chat model when you provide the prompt and task. The prompts are in their original language; supporting instructions and examples are bilingual.

## How to use the library

1. Choose a task below and open its assistant guide.
2. Check the model/tool guidance and the example input.
3. Open that assistant's `prompt.md` file and paste it into a new chat's instruction field, or send it as the first message.
4. Send your real task separately and review the result before relying on it.

## Adding or updating an assistant

Edit the entry in [`data/assistants.json`](./data/assistants.json), keeping its ID, slug, category, use case, setup guidance, fictional examples, and original prompt aligned. Then run `python tools/build_catalog.py` to regenerate the per-assistant guides and both catalogs. Keep the published library count generated from the data; do not hard-code it in descriptions.
